# TTS 后端：当前实现与联调

更新：2026-10-23。本文描述已写入代码的缓冲播放原型；目标设计中的流式低延迟播放仍待实现。

## 使用步骤

1. 桌面应用 → 设置 → 语音合成，选择接口协议，填地址、模型 ID 和音色 ID；独立保存 API Key，再保存更改。
2. 常规 → 音频，刷新并选择试听设备（耳机 / 扬声器）、发送设备（已安装的虚拟音频设备），保存更改。
3. 工作台输入文字。耳机按钮试听输入文字；箭头按钮将输入文字合成并输出至发送设备。点击翻译后，可对译文单独选择“试听译文”或“发送译文”。没有自动翻译或自动发送。
4. 任务期间显示合成 / 准备播放 / 试听或发送状态，方形按钮停止当前任务。一次只处理一个语音任务，避免重叠；诊断测试音与语音播放共用互斥锁。

试听与发送使用独立路由，发送时拒绝与试听相同的设备。发送设备只是输出目的地，应用不能据此证明它一定是虚拟设备。需用户手动安装 BlackHole 等设备并在 Discord 选择相应麦克风输入；软件不安装驱动、不改系统默认设备、不自动回退输出。

## 协议契约

| 适配器 | 地址填写 | 请求与响应 |
| --- | --- | --- |
| `minimax_tts_ws` | 完整 WSS 地址，例如 `wss://api.minimax.io/ws/v1/t2a_v2` | Bearer 认证；connected_success → task_start → task_started → task_continue → 十六进制 MP3 分片 → is_final / task_finished → task_finish |
| `openai_audio_speech` | API 根地址，例如 `https://api.example.com/v1` | 自动追加 `/audio/speech`；Bearer 认证；model、voice、input、response_format=mp3；接收音频字节 |

远程只接受 HTTPS / WSS；回环地址可使用 HTTP / WS。地址不能包含用户凭据、查询参数或片段。HTTP 不跟随重定向，WebSocket 不追随重定向；TLS 证书验证保持开启。模型和音色手动配置，不硬编码供应商套餐或模型列表；不同阶段的凭据互不自动复用。

协议依据：[MiniMax WebSocket TTS](https://platform.minimax.io/docs/api-reference/speech-t2a-websocket)、[OpenAI Create speech](https://developers.openai.com/api/reference/resources/audio/subresources/speech/methods/create)。兼容服务是否实现这些字段仍须真实请求验证，不能以 Key 前缀判断。

## 执行与资源边界

当前路径：配置快照 → 校验 → 注册任务 → 读取系统凭据 → 打开明确选择的输出设备 → 调用服务 → 完整音频缓冲 → 解码 → 播放 → 清理。

- 先打开输出设备，失败则不提交付费合成请求。等待音频时设备保持打开，发生设备错误会取消上游任务。
- 合成超时 60 秒；HTTP 连接超时 10 秒；WS 单消息 / 单帧最多 512 KiB；累计压缩音频最多 8 MiB。
- MP3 / WAV 解码限定 1–2 声道、8–96 kHz；最多 120 秒且不超过 1200 万个浮点采样，先达到的上限生效。播放最多等待 125 秒。
- 使用 Rodio / CPAL 完成输出采样转换；音频流在专用阻塞线程创建及销毁，兼容 macOS 的线程约束。接收和解码有界，当前不是实时边解码播放方案。
- 不把音频、文本或 Key 写入磁盘；网络错误不回显原始供应商响应或认证头。普通配置仅保存路由和模型等非敏感信息。
- 输出设备暂按名称唯一匹配，同名或消失会拒绝使用；稳定平台 UID、睡眠恢复和断连后的重新连接仍待 Mac 实机实现。

## 停止与状态

每次调用携带唯一 requestId。停止在网络请求阶段取消异步任务，在解码阶段定期检查取消标志，在播放阶段约每 20 ms 检查并停止、释放输出流。硬件已提交的缓冲可能仍有短暂尾音，真实停止延迟待实测，不承诺 20 ms 内物理静音。

停止早于任务注册时保留有界取消记录（64 条）；旧任务的停止不能取消新任务。前端按 requestId 丢弃晚到进度，任务完成或失败后才开放下一次操作。任务使用提交时的文本、配置及设备快照，运行时改设置不重定向已有声音。取消不代表供应商退费，失败后不会自动重试产生第二笔请求。

## 验证状态

已通过：本机 HTTP 模拟服务的请求字段、音频字节返回、认证错误脱敏；本机 WebSocket 模拟服务的任务顺序、分片合并和握手失败；等待连接时取消；早停 / 并发 / 过期停止隔离；容量边界；自行生成的 MP3 解码及无效音频拒绝；旧配置迁移与 TTS 协议校验。

测试夹具 `src-tauri/src/speech/fixtures/tone.mp3` 为自行生成的 440 Hz 正弦波（32 kHz、单声道、约 120 ms），没有第三方录音内容。自动测试不会实际打开音频设备或使用真实 Key。

尚未验证：真实供应商请求、模型 / 音色权限、音质、实际输出、停止尾音、Mac Keychain / 音频设备、BlackHole 回录、Discord 对端、长时间稳定性。收到服务配置后分别记录，不能把模拟测试当作真实验收。
