# VoxBridge 0.3.0 测试版

本版首次提供 Windows 安装包，并继续维护与 Mac 共用的界面和业务流程。

## 下载

- **Windows 11 x64**：`VoxBridge_0.3.0_x64-setup.exe`。
- **Windows ARM64（实验版）**：`VoxBridge_0.3.0_arm64-setup.exe`。原生 CI 和打包已覆盖，真实音频硬件尚未验收。
- **Apple Silicon Mac、macOS 14.2+**：`VoxBridge_0.3.0_aarch64.dmg`，打开后拖入「应用程序」。
- `.sig`、`latest.json`、`.app.tar.gz` 为签名更新或校验产物；普通安装请选择 EXE 或 DMG。`Source code` 不是安装程序。

## 本次更新

- Windows 按应用监听、语音输入、翻译、语音合成、发送队列、试听和浮窗；应用列表使用 Edge、Oopz、KOOK 等可读名称。
- Windows 安装器复用应用前端，统一深色卡片、字体、按钮和布局；可选择安装位置、桌面快捷方式和虚拟麦克风。缺少 WebView2 时使用原生兼容向导安装运行环境。
- 随包提供完整的 VB-Audio 官方签名 VB-CABLE 基础版及安装/卸载管理入口；驱动为可选项，需要管理员授权，可能需要重启电脑。
- 新版本可以直接覆盖安装，保留已有设置、服务配置和本机密钥，无需先卸载。Windows 主密钥使用当前用户 DPAPI，旧格式会在验证后迁移。
- 启动检查与设置页手动检查更新，更新包验证签名和签名版本后安装；监听、录音、队列、草稿或未保存设置存在时阻止应用内安装更新。
- 单个发送失败不会阻塞后面的请求，队列入口统一并提示失败；译文校验失败只影响该句，后续监听继续。
- 默认音频设备、设备旧名称迁移、重复试听、工作台字幕字号、滑块边框和设置排版优化。
- 启动时使用跟随主题的声波加载动画，减少白屏；加载异常时提供重新加载入口。

## 安装与升级

1. Windows 用户运行对应架构 EXE；Mac 用户拖入「应用程序」。旧 Mac 0.2.1 没有应用内更新入口，需要手动下载新版。
2. Windows 如需向 Discord、Oopz、KOOK 等发送语音，安装 VB-CABLE：VoxBridge 发送到 **CABLE Input**，聊天软件输入选择 **CABLE Output**。可在 Windows 声音设置修改显示名为 VoxBridge，厂商与驱动身份仍为 VB-Audio。
3. 首次使用请配置自己的模型服务与 API Key。安装包不包含密钥、云服务额度或私人克隆音色；供应商服务可能计费。
4. Windows 开始菜单提供 VoxBridge、软件卸载及驱动管理入口。普通卸载默认保留驱动与应用数据；主动勾选清除数据才会删除本机配置和凭据。

## 测试范围与限制

- Windows x64 已做本机音频回环、设备枚举与多项安装/恢复测试。Windows x64、ARM64、Mac 与前端的自动检查及签名发布构建分别执行。
- Windows 10、干净机器完整安装矩阵、长期运行、真实聊天软件全部通话场景和 Mac 全量实机回归尚未完成，作为测试版发布，不保证所有环境兼容。
- 更新包具有 VoxBridge 更新签名；**Windows 程序尚未做 Authenticode 签名，Mac 尚未做 Developer ID 签名或公证**。VB-CABLE 的厂商签名不等于整个应用已获系统厂商签名。
- Mac 首次运行如被系统拦截，请按 [Apple 官方说明](https://support.apple.com/zh-cn/102445)在「隐私与安全性」允许打开；无需关闭系统整体安全保护。
- Windows 仍使用第三方 VB-CABLE；独立自有签名虚拟麦克风驱动尚未实现。
