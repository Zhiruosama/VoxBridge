# VoxBridge 0.6.0

Windows x64、Windows ARM64 和 Apple Silicon Mac 桌面测试版。

## 新增

- OpenAI 兼容语音识别：支持 Whisper、GPT-4o Transcribe、Mini Transcribe 和 Diarize 模型，用于录音、短音频诊断和应用声音的分段识别；当前字幕不展示说话者标签。
- 俄语界面、安装卸载界面和使用文档。
- 可选的「上下文语气」：MiniMax 译文语音参考近期对话调整情绪和语速，手动情绪优先，默认关闭。

## 修复与体验

- 桌面应用单实例：再次启动恢复已有窗口；安装、卸载、更新界面可独立运行。
- 修复更新提示被隐藏的问题，展示检查、下载和重启倒计时；Windows 更新安装采用共享 GUI。
- 剪贴板监听和草稿未结束时暂缓自动安装更新。
- 悬浮窗发送增加接收确认，保护后续编辑草稿；修复输入法事件或状态更新漏收后 Enter 失效的问题。
- GNU Windows 安装包携带 WebView2 动态加载器。

## 使用说明

安装新版保留用户配置和密钥。本次不包含任何个人服务密钥或体验预设。Windows 通话软件需选择 VoxBridge / VB-CABLE 虚拟麦克风；Mac 隐私权限可能需要重新确认。

发布流水线通过三个平台的测试、签名打包和校验后统一上传安装包并推进更新源。真实付费服务、所有聊天客户端和所有设备组合未逐一验证；Mac 当前使用 ad-hoc 签名，尚未 Developer ID 签名或公证。
