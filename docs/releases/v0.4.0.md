# VoxBridge 0.4.0 测试版

本版新增独立文本翻译，完善请求恢复、服务测试和语音设置，并修复 Mac 窗口与悬浮字幕的多项问题。

## 下载

- **Apple Silicon Mac、macOS 14.2+**：`VoxBridge_0.4.0_aarch64.dmg`，打开后拖入「应用程序」。
- **Windows 11 x64**：`VoxBridge_0.4.0_x64-setup.exe`。
- **Windows ARM64（实验版）**：`VoxBridge_0.4.0_arm64-setup.exe`，真实音频硬件仍待验收。
- `.sig`、`latest.json`、`.app.tar.gz` 和 `SHA256SUMS` 用于签名更新或校验；普通安装请选择 DMG 或 EXE。`Source code` 不是安装程序。

**本轮 Windows 实机回归由后续补充。** Windows 安装包执行自动构建与测试，但不将其视为新功能、设备热插拔或真实聊天软件通话的实机验收。

## 本次更新

### 独立文本翻译

- 左侧新增「文本翻译」，只调用文字翻译服务，不调用 ASR、TTS 或麦克风。
- 自动识别原文语言、选择目标语言、复制译文；Enter 提交，Shift + Enter 换行，支持输入法确认保护。
- 原文与译文分栏，支持拖动比例、双击恢复等宽、窄窗口上下排列和背景不透明度设置。
- 切页保留当前输入与结果；翻译时可继续编辑，重试旧请求不会覆盖新草稿。内容不写入持久化翻译历史。

### 请求恢复与设置

- 文本翻译显示等待时间与慢响应提示，45 秒截止后保留内容，支持取消和手动重试；不自动重复请求。
- 网络、密钥、额度、设备等错误提供对应建议，详细错误按需展开。
- 队列入口保持简洁的「队列」，点开后查看阶段、数量和单项操作。
- 翻译服务增加短请求测试，语音合成可静默生成短测试音频；测试仅手动触发，可能计费，不播放、不发送到通话。
- ASR 提供配置/密钥检查和音频诊断入口；本地配置通过不等于识别服务可用。
- 翻译扩展参数按需展开，避免将厂商扩展选项误认为所有服务均支持。

### 音色与 Mac 窗口

- 自定义音色可保存为预设，切换后不必重复输入。
- MiniMax 增加模型支持范围内的情绪、音量、音调、音色修饰、音效及发音替换设置。
- 恢复 Mac 原生窗口布局，标题栏跟随软件主题，保持 Windows 独立窗口布局。
- 悬浮窗跨显示器拖动使用原生全局指针坐标；修复显示器缩放/尺寸回调时隐藏宿主视图为空导致的崩溃。
- 简化悬浮窗边缘，统一文字翻译页的字体、焦点和阴影。

## 升级与注意事项

- 可以覆盖安装，保留已有设置、服务配置和密钥。应用内更新会验证更新包签名；有监听、录音、待发送内容、草稿或未保存配置时，请先结束或保存再安装更新。
- 服务测试、翻译及语音合成按供应商规则计费。私人克隆音色不包含在安装包中，也不保证跨供应商账号共享；克隆音色首次生成还可能涉及厂商音色费用。
- Windows 虚拟麦克风继续使用可选的 VB-CABLE，路由及安装方式见[Windows 安装指南](https://github.com/Zhiruosama/VoxBridge/blob/v0.4.0/docs/windows-installation.md)。
- 更新包的 VoxBridge 签名不等于系统厂商签名：**Windows 程序尚未做 Authenticode 签名，Mac 尚未做 Developer ID 签名或公证**。
- Mac 首次打开受阻时，按 [Apple 官方说明](https://support.apple.com/zh-cn/102445)在「隐私与安全性」允许打开，无需关闭系统整体安全保护。

## 验证范围与已知限制

- 本地 218 项前端测试、153 项 Rust 测试、5 项发布脚本测试及 Mac app 构建/签名检查通过；另有 23 项 Rust 测试默认忽略，不计入通过项。
- 本轮新服务测试流程使用模拟桥接和自动测试验证，未重新执行真实付费云服务及通话验收。
- Windows 本轮实机回归待补充；Windows 10、ARM64 真实音频硬件及干净机器完整安装矩阵尚未完成验收。
- Mac 多屏与崩溃修复有原生回归，但显示器拔插、休眠唤醒及长时间使用仍需观察。
- QQ / 微信虚拟麦克风兼容性仍有环境限制，见 [issue #1](https://github.com/Zhiruosama/VoxBridge/issues/1)，不保证所有版本均能枚举或使用。
