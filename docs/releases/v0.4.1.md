# VoxBridge 0.4.1 测试版

本版修复侧栏拖动导致工作区变形、Mac 主题切换中断，并补齐 Windows 麦克风选择、短文本识别和音频恢复边界。

## 下载

- **Windows 11 x64**：`VoxBridge_0.4.1_x64-setup.exe`。
- **Windows ARM64（实验版）**：`VoxBridge_0.4.1_arm64-setup.exe`。
- **Apple Silicon Mac，macOS 14.2+**：`VoxBridge_0.4.1_aarch64.dmg`。
- `.sig`、`latest.json`、`.app.tar.gz` 和 `SHA256SUMS` 用于签名更新或校验；普通安装选择 EXE 或 DMG。

## 本次修复

### 工作区布局

- 主窗口最小宽度设为 1000 逻辑像素；侧栏根据当前窗宽限宽，为右侧工作区保留空间。
- CSS 与拖动逻辑共同限制侧栏宽度，避免窗口变化时旧宽度暂时挤压主区。
- 文本翻译仅在真正放不下双栏的窄屏环境切为上下排列，正常桌面窗口拖动侧栏仍保持原文、译文左右分栏。
- 底部语音工具栏保持单行；默认窗口尺寸和悬浮字幕窗口尺寸不变。

### Mac 主题切换

- 显式选择深色/浅色时，不再让原生标题栏的颜色通知重新触发并取消页面动画。
- “跟随系统”忽略重复颜色通知，快速切换时防止旧请求再写入背景。
- 不支持 View Transition 的 WebView 批量处理滚动位置，等旧画面绘制后再淡出；保留编辑内容和滚动位置。

### Windows 后端与设置保护

- 补充离线短文本语言识别，复用受支持语言模型；不确定或混合文字仍保守处理，不调用云服务识别语言。
- 采集启动阶段遇到设备/资源暂时失效或音频服务未运行时进入有界恢复；权限和格式错误不盲目重试。
- 输出设备列表跳过中途断开的单个端点；输入设备显示完整名称。
- 麦克风筛选避免仅凭自定义名称包含 VoxBridge 就误判；自动选择避开自身虚拟回送，明确指定的失效设备不自动换成别的麦克风。
- 在连接 ASR 前检查并固定输入设备，避免无效麦克风先启动识别请求。
- 保存设置时保留有效备份，主记录损坏或缺失时可回退；损坏原文另行保留，备份写入失败时不覆盖当前记录。

## 升级和使用

- 可覆盖安装，保留已保存服务配置、设置和密钥。应用内更新验证包签名与版本；开始前请结束任务、保存草稿和设置。
- VoxBridge 运行时不主动修改 Windows 系统默认录音或通信设备。正常说话时系统输入应为实体麦克风；要让聊天软件接收合成语音，请在该软件内明确选择 `VoxBridge (VB-Audio Virtual Cable)`，并确认该输入没有被静音。
- Windows 继续使用可选的官方 VB-CABLE；端点改名不等于自有 Windows 驱动。
- 更新包签名不等于系统代码签名：Windows 尚无 Authenticode，Mac 尚无 Developer ID 签名或公证。

## 验证与限制

- 232 项前端测试、Windows 155 项默认 Rust 测试及严格 Clippy 通过；24 项 Windows 手动测试不计入默认通过项。发布流程另执行各平台测试、打包、签名和校验。
- Windows 本机实际侧栏往返拖动、文本翻译双栏、原服务配置加载、只读设备解析及覆盖安装前后的设置/密钥完整性已核对。
- 本轮未采集用户语音、未重新调用付费云服务或验收真实通话。Mac 主题动画观感、设备热插拔/休眠、ARM64 音频硬件和干净机器安装矩阵仍待进一步实机验证。
