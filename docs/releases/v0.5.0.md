# VoxBridge 0.5.0 测试版

本版新增剪贴板翻译与独立翻译悬浮窗，优化字幕阅读、识别纠错和 Mac 窗口操作。

## 下载

- **Apple Silicon Mac，macOS 14.2+**：`VoxBridge_0.5.0_aarch64.dmg`，打开后拖入「应用程序」。
- **Windows 11 x64**：`VoxBridge_0.5.0_x64-setup.exe`。
- **Windows ARM64（实验版）**：`VoxBridge_0.5.0_arm64-setup.exe`。
- 普通安装请选择 DMG 或 EXE。`.sig`、`latest.json`、`.app.tar.gz` 和 `SHA256SUMS` 用于签名更新或校验，`Source code` 不是安装程序。

## 本次更新

### 剪贴板翻译与独立小窗

- 文本翻译页可开启剪贴板监听。复制文字后，可以先确认、编辑再翻译，也可以开启自动翻译。
- 新增独立翻译悬浮窗，支持开始／暂停剪贴板监听、切换自动翻译、手动翻译、复制译文和返回主窗口。
- 小窗背景不透明度、字号、行距和文字颜色可分别设置，调整即时同步，保存后重启保留。
- 监听与自动翻译每次启动默认关闭。开启前已有的剪贴板内容不自动导入，不建立剪贴板历史；重复内容和应用自身复制会去重，超长文字提示处理。新复制内容会淘汰旧请求，避免迟到结果覆盖。
- 自动翻译会将复制的文字发送给所选翻译服务，可能产生费用；纯文本翻译不调用 ASR 或语音合成。

### 字幕阅读与识别

- 工作台与语音字幕悬浮窗支持按段落阅读，保留原有逐句显示方式；优化阅读位置与自动跟随。
- 悬浮字幕可切换双语或仅译文，与设置同步。
- 保留 ASR 最终结果对临时识别的纠正，并更新受影响译文，减少提前固定错误文字的问题。
- 改善 HTTP 分段对短回答的保留，补充支持模型的识别语言提示及音频质量诊断。此项不代表更换了默认 ASR 模型或实现了说话人区分。

### Mac 窗口体验

- 主窗口关闭后默认隐藏，可从 Dock 返回；也可在设置中选择关闭即退出。
- 扩大悬浮窗边缘和角落的缩放范围，方便调整宽高。
- 语音字幕与文本翻译小窗分别管理，避免多个浮窗互相影响。

## 升级与限制

- 支持覆盖安装，保留已保存设置、服务配置和密钥。更新前请结束当前任务并保存草稿与设置。
- 发布流程对三个平台分别执行测试、打包与校验，全部成功后发布安装包与更新清单。
- 本轮 Mac 已完成本地构建和原生浮窗回归；剪贴板流程使用模拟文字与模拟翻译服务验证，未读取用户剪贴板或调用付费模型。Windows 新功能及 ARM64 音频硬件仍需实机体验，自动构建通过不等于真实通话验收。
- Windows 继续使用可选的官方 VB-CABLE。应用不会主动更改系统默认录音或通信设备。
- 更新包签名不等于系统代码签名：Mac 尚无 Developer ID 签名或公证，Windows 尚无 Authenticode 发布者签名。
