# VoxBridge 0.5.1 测试版

本版优化新版本提醒，沿用界面已有的小提示样式。

## 下载

- **Apple Silicon Mac，macOS 14.2+**：`VoxBridge_0.5.1_aarch64.dmg`。
- **Windows 11 x64**：`VoxBridge_0.5.1_x64-setup.exe`。
- **Windows ARM64（实验版）**：`VoxBridge_0.5.1_arm64-setup.exe`。
- 普通安装请选择 DMG 或 EXE；其余签名、更新清单和校验文件用于应用内更新及完整性校验。

## 本次更新

- 每次启动检查到新版后，在软件顶部显示一次小提示，提供「更新」和「稍后」。没有大弹窗、遮罩，也不抢输入焦点。
- 点击「稍后」后，本次运行不再重复提醒；下次启动重新检查。检查失败或已是最新版时不显示提醒，仍可到设置中手动检查。
- 点击更新后显示下载和安装进度；下载失败或签名校验失败时保留当前应用，可重试。
- 保留监听、录音、发送队列、未保存设置及草稿保护，并补充剪贴板监听和纯文本翻译任务检查，避免更新重启中断工作。
- 提醒支持中英文、浅色和深色主题；与其他提示错开显示。

## 升级与限制

- 可以覆盖安装，保留同一用户、同一电脑上已保存的配置和密钥。更新前请结束任务并保存草稿与设置。
- 从旧版本升级到本版后，新的顶部提醒会在以后发现更高版本时生效；旧安装包不会自动获得新的提醒样式。
- 本地 261 项前端测试通过，含每次启动只提醒一次、稍后不再提醒、离线或无新版时保持安静、安装前活动保护；浏览器模拟检查过提示样式和失败恢复，未执行真实下载或重启。发布流程另执行三平台测试、打包与校验。
- Windows ARM64 音频硬件仍需实机验证。Windows 尚无 Authenticode 发布者签名，Mac 尚无 Developer ID 签名或公证；更新包签名与系统代码签名不同。
