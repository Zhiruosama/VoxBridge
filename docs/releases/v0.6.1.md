# VoxBridge 0.6.1 测试版

适用于 Apple Silicon Mac、Windows x64 和 Windows ARM64。

- 设置侧栏支持搜索。输入关键词后，左栏列出匹配入口，点击即可定位到右侧设置项。长标题随侧栏宽度自动省略。
- 从设置返回时会恢复此前的工作台页面。调整了输入工具栏对齐和 macOS Dock 图标的留白。
- 监听字幕和麦克风录音可分别选择识别语言，新增可选的 Groq 识别预设。
- 改进字幕翻译对近期已校正内容的利用，单句翻译失败时可继续识别后续语音。

**Windows 验证范围**：x64 和 ARM64 安装包经过发布流水线的自动化测试、构建与校验。此版本尚未完成 Windows 实机验收，包括安装升级、音频设备和不同显示缩放下的界面体验。
