# VoxBridge 0.5.4 测试版

本版增加可选自动更新，改善 Windows 托盘与卸载体验，并调整共享界面的默认外观。

## 下载

- **Apple Silicon Mac，macOS 14.2+**：`VoxBridge_0.5.4_aarch64.dmg`。
- **Windows 11 x64**：`VoxBridge_0.5.4_x64-setup.exe`。
- **Windows ARM64（实验版）**：`VoxBridge_0.5.4_arm64-setup.exe`。
- 普通安装请选择 DMG 或 EXE；签名、更新清单与校验文件用于应用内更新及完整性校验。公开安装包不包含服务密钥。

## 本次更新

- 「设置 → 常规 → 关于」新增自动更新开关，默认关闭。开启后启动时检查并下载签名更新，空闲时倒计时 5 秒安装并重启；可点「稍后」推迟本次安装，保留手动检查与更新。
- 更新提示增加阶段过渡、下载进度和安装动画，支持减少动态效果。进行中的任务及未保存设置阻止安装；手动更新暂存输入草稿并在重启后恢复，自动更新等待用户处理草稿，暂存失败不安装。
- Windows 关闭主窗口默认隐藏到系统托盘，任务栏不保留运行窗口；点击托盘恢复，右键可打开或真正退出。顶部最小化按钮仍最小化到任务栏，也可在设置中选择关闭即退出。托盘注册失败时保留任务栏作为恢复入口。
- Windows 卸载器改用安装程序同款界面，统一布局、字体、语言切换及窗口按钮。配置和共享音频驱动默认保留。
- 修复应用运行或文件占用导致卸载中断后维护入口丢失的问题：任何清理前先检查，成功后才删除维护快捷方式；中断后仍可重试。
- 调整新用户与「恢复默认」的共享外观：工作台字幕 17px、段落间距 15px、识别黄色；字幕浮窗 16px、行距 1.3、背景不透明度 59%。已有保存的外观和服务配置不覆盖。

## 更新与验证范围

- 可通过原安装目录覆盖更新，或在软件设置中检查更新；同一用户的配置与密钥保留，无需卸载旧版本。
- 本地前端 298 项测试及 Windows 原生托盘、卸载中断保护检查通过。三平台编译、测试、打包及更新签名校验由发布流程执行。
- 本轮实机范围主要为 Windows x64；ARM64 音频硬件、Mac 实机回归及长期后台任务仍需分别验证。
- Windows 尚无 Authenticode 发布者签名，Mac 尚无 Developer ID 签名或公证；更新包签名与系统代码签名不同。
