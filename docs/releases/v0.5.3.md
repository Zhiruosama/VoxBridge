# VoxBridge 0.5.3 测试版

本版主要改善 Mac 的窗口操作、主题切换和悬浮窗输入体验，并修复更新被草稿阻挡的问题。

## 下载

- **Apple Silicon Mac，macOS 14.2+**：`VoxBridge_0.5.3_aarch64.dmg`。
- **Windows 11 x64**：`VoxBridge_0.5.3_x64-setup.exe`。
- **Windows ARM64（实验版）**：`VoxBridge_0.5.3_arm64-setup.exe`。
- 普通安装请选择 DMG 或 EXE；其余签名、更新清单和校验文件用于应用内更新及完整性校验。

## 本次更新

- Mac 双击顶栏铺满桌面、再次双击还原，改用 AppKit 原生窗口动画；修复缩放后的内容裁切、右侧空白和跨屏还原位置问题。
- Mac 标题栏和页面由同一套主题过渡绘制，统一深浅色切换；调整红黄绿按钮位置，并恢复顶栏拖动。
- 调整 Mac 全屏桌面上的字幕浮窗输入：编辑时使用可激活的原生面板，收起后恢复跨桌面的字幕显示；移除造成输入内容和占位提示重叠的实验输入控件。
- 更新前自动保存可恢复的输入草稿，减少已经停止监听、保存设置后仍被阻止更新的情况；进行中的任务仍需先结束。
- 简化设置中的模型预设区域，统一服务扩展参数和测试区域排版，移除冗余说明。
- 修复 Windows 编译兼容问题，Windows 现有窗口操作方式保持不变。

## 升级与验证范围

- 可覆盖安装，保留同一用户、同一电脑上的配置与密钥。发布后，已有版本也可通过应用内检查更新升级。
- Mac 本机 283 项前端测试、172 项 Rust 测试及打包签名检查通过；另有 23 项依赖真实设备或服务的集成测试默认忽略。
- 原生窗口检查覆盖铺满与还原、页面中间绘制尺寸、多个显示器及非全屏状态；全屏浮窗输入通过独立测试场景验证，Discord／Chrome 的实际工作区组合仍欢迎反馈。
- 编辑字幕浮窗期间，Mac 的 Dock 图标可能暂时隐藏，收起输入后恢复。
- Windows ARM64 音频硬件仍需实机验证。Windows 尚无 Authenticode 发布者签名，Mac 尚无 Developer ID 签名或公证；更新包签名与系统代码签名不同。
