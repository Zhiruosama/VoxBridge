# VoxBridge 0.6.4 测试版

适用于 Apple Silicon Mac、Windows x64 和 Windows ARM64。

- **语音可以句中暂停和续播。** 在主窗口或字幕悬浮窗按暂停，虚拟麦克风输出和本地试听会一起停住。再按一次从原位置继续，队列中的下一条会等当前语音播完。
- **支持全局暂停快捷键。** 在「设置 → 常规 → 文字表达 → 语音暂停快捷键」保存组合键，在通话软件处于前台时也能暂停或继续。默认关闭。
- **文本翻译每次最多 10,000 字符。** 手动输入和剪贴板翻译均支持这一上限。左下角只显示当前字数，超限时保留原文并提示缩短。长请求有更多响应时间，完整译文可以在文本浮窗中查看和复制。
