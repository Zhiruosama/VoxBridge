VoxBridge 0.2.1 测试版。本次主要完善界面体验，修复主题切换时标题和标签颜色滞后的问题，核心音频流程保持与 0.2.0 一致。

## 本次更新

- **侧栏宽度可调整**：左右拖动侧栏边界，松开后自动保存；双击恢复默认，也支持方向键微调。窄窗口自动限制宽度，收起后再展开保留原宽度。
- **简洁的拖动边界**：悬停与拖动时不再出现额外的加粗长竖线，保留鼠标指针提示与键盘焦点提示。
- **主题切换更柔和**：背景、文字、边框和阴影通过统一主题颜色变量渐变，修复嵌套文字逐层延迟的问题。尊重系统“减少动态效果”设置，首次打开不播放切换动画。
- **ASR 诊断页面优化**：配置名称、协议与模型分层显示；文件选择控件统一风格，长文件名自动省略，窄窗口和中英文界面均可正常排版。
- **架构文档补充**：新增整体结构、字幕流水线、恢复状态、语音输入、发送队列、浮窗同步和存储边界等 7 张 Mermaid 图，并更新内部逻辑说明。

发布前已通过 157 项前端测试、139 项原生测试及 Mac 打包检查。自动化检查不替代不同机器、聊天软件和实际音质的验收。

## 下载与安装

下载下方 **VoxBridge_0.2.1_aarch64.dmg**，适用于 **Apple Silicon（M 系列）Mac、macOS 14.2 或更新系统**。本次不提供 Intel Mac 或 Windows 安装包。

无需安装 Node.js、Rust、Homebrew 等开发工具。`Source code` 是源码压缩包，不是安装程序。可用 `SHA256SUMS.txt` 校验下载文件。

1. 打开 DMG，把 VoxBridge 拖入「应用程序」，再从「应用程序」启动。
2. 从 0.1.0 / 0.2.0 升级时，先退出 VoxBridge，再替换应用；原有设置和本机保存的密钥会保留，无需卸载或清理应用数据。
3. 本测试版使用临时签名，**尚未使用 Apple Developer ID 签名或公证**。首次打开或升级后，macOS 可能重新确认安全与录音授权。确认下载来源为本仓库后，可按 [Apple 官方说明](https://support.apple.com/zh-cn/102445)在「系统设置 → 隐私与安全性」允许打开。无需关闭系统整体安全保护。
4. 首次使用请配置自己的语音识别、翻译、语音合成服务与 API Key。密钥保存在自己的电脑，安装包不附送密钥、额度或私人克隆音色；云服务可能计费。
5. 需要向 Discord 等软件发送语音时，在「设置 → 常规 → 音频」安装虚拟麦克风，并将发送设备与 Discord 输入设备设为 VoxBridge。驱动安装会重启系统音频服务，请先结束通话；已安装且正常工作的用户无需重新安装。

## 已知限制

- 这是未经公证的测试版本，尚未完成其他用户干净机器上的完整安装验收。
- Discord 为主要实测场景；QQ、微信的设备枚举兼容性仍在排查。本机曾使用的临时兼容设备不包含在安装包中，不能保证这两个软件能列出虚拟麦克风。
- 各服务的识别、语言与音色能力不同，自定义克隆音色需使用者自行提供有权限的音色。
- 无自动更新功能，后续版本请回到 Releases 下载。
