# VoxBridge 0.5.2 测试版

本版补齐 Windows 文本翻译浮窗，并改善首次使用虚拟麦克风时的默认路由和发送前检查。工作台不再常驻显示设备及配置提示，只在使用对应功能时提示问题。

## 下载

- **Apple Silicon Mac，macOS 14.2+**：`VoxBridge_0.5.2_aarch64.dmg`。
- **Windows 11 x64**：`VoxBridge_0.5.2_x64-setup.exe`。
- **Windows ARM64（实验版）**：`VoxBridge_0.5.2_arm64-setup.exe`。
- 普通安装请选择 DMG 或 EXE；其余签名、更新清单和校验文件用于应用内更新及完整性校验。

## 本次更新

- 补齐 Windows 平台窗口配置中遗漏的文本翻译浮窗，恢复独立窗口及主窗口同步，增加平台配置和原生窗口回归检查。
- 新配置默认将语音发送到虚拟麦克风，试听仍跟随系统默认输出。虚拟设备未完整就绪时给出错误，不退回扬声器；已有用户明确保存的设备保持不变，不更改 Windows 默认麦克风。
- 使用翻译或语音发送时，先检查所需服务配置及输出设备。未通过时保留输入、不接受进发送队列；原文发送仍可绕过翻译，同语言输入仍可跳过不必要的翻译。
- 编辑排队文字后废弃旧语言预检结果，避免沿用旧判断而跳过翻译。
- 移除工作台常驻路由和配置提示；设备与录音流程说明保留在设置和指南中。设置中尚未保存的虚拟发送选择明确显示「保存更改后生效」。
- 增加启动配置加载的数量诊断，不记录服务地址、配置正文、密钥或聊天内容。
- 包含 0.5.1 发布后主分支的 Mac 标题栏主题过渡、虚拟麦克风测试入口，以及 Windows 驱动安装期间默认设备保护修复。

## 升级与验证范围

- 可覆盖安装，保留同一用户、同一电脑上的配置与密钥。更新前请结束任务并保存草稿与设置；已有扬声器发送配置需要自行到音频设置选择虚拟麦克风并保存。
- 本机 277 项前端测试、171 项 Windows Rust 测试通过，25 项真实设备/服务测试默认忽略；严格 Clippy、格式、生产构建、原生隐藏窗口创建和只读虚拟设备解析检查通过。覆盖更新前后设置记录逐字节相同，凭据文件指纹相同。
- 本地曾收到配置短暂显示默认值的反馈；只读持久数据和重开后的实际界面均完整，尚未复现原因。本版增加定位日志，不宣称已经修复了一个确定的配置删除问题。
- 不声明已通过对方 QQ 通话、真实麦克风、长期监听或完整浮窗缩放验收。测试音播放成功和设备存在均不能代替聊天软件实际收音。
- Windows ARM64 音频硬件仍需实机验证。Windows 尚无 Authenticode 发布者签名，Mac 尚无 Developer ID 签名或公证；更新包签名与系统代码签名不同。
