VoxBridge 首个公开测试版：在 Mac 上接收应用声音并显示双语字幕，也可以输入文字或录音，翻译后通过虚拟麦克风发送语音。

## 下载

下载下方 **VoxBridge_0.1.0_aarch64.dmg**。这是 Apple Silicon（M 系列芯片）版本，要求 **macOS 14.2 或更新系统**。本次不提供 Intel Mac 或 Windows 安装包。

无需安装 Node.js、Rust、Homebrew 或其他开发工具。`Source code` 是源码压缩包，不是安装程序。可用 `SHA256SUMS.txt` 校验下载文件。

## 安装与首次配置

1. 打开 DMG，把 VoxBridge 拖入「应用程序」，再从「应用程序」启动。
2. 本测试版使用临时签名，**尚未使用 Apple Developer ID 签名或公证**，首次打开可能被 macOS 拦截。确认下载来源为本仓库后，可按 Apple 官方说明在「系统设置 → 隐私与安全性」允许打开：https://support.apple.com/zh-cn/102445 。如果系统没有提供允许选项，请反馈具体提示；无需关闭系统整体安全保护。
3. 在设置中配置自己的 ASR、翻译、TTS 服务及 API Key，并保存密钥。密钥保存在自己的电脑，重启后自动恢复；安装包不附送密钥、额度或私人克隆音色。云服务可能计费。
4. 按实际功能需要授予麦克风及应用声音采集相关权限。
5. 需要向 Discord 等软件发送合成语音时，在「设置 → 常规 → 音频」点击「安装虚拟麦克风」，完成系统安装器的管理员授权。安装会重启系统音频服务，请先结束通话。
6. 回到 VoxBridge 刷新设备，把发送设备设为 VoxBridge，试听设备可选择「系统默认」。Discord 网页的输入设备选择 VoxBridge，输出设备保持耳机或扬声器；设备列表未更新时，完全退出并重新打开 Chrome。

## 本版功能

- 按应用监听、实时语音识别与双语字幕。
- 可跟随全屏空间的悬浮字幕窗，支持文字和语音输入。
- 语音转文字后编辑确认，或结束录音后直接翻译发送。
- 文字翻译、流式语音合成、虚拟麦克风输出及独立试听开关。
- 发送队列：翻译和语音准备可并行，播放按顺序进行；失败项支持编辑、重试、取消。
- 多服务配置、自定义模型和音色预设、快速切换音色、语速调节。
- 自定义翻译提示词、字幕颜色与多语言输出。
- 试听输出可跟随系统默认设备。

## 已知限制

- 这是未经公证的测试版本，尚未完成其他用户干净机器上的完整安装验收。
- Discord 为主要实测场景；QQ、微信的设备枚举兼容性仍在排查。本机曾使用的临时兼容设备不包含在安装包中，不能保证这两个软件能列出虚拟麦克风。
- 各服务的识别、语言、音色能力不同，自定义克隆音色需使用者自己提供有权限的音色 ID。
- 无自动更新功能；后续版本请回到 Releases 下载。
