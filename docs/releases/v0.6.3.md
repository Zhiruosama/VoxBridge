# VoxBridge 0.6.3 测试版

适用于 Apple Silicon Mac、Windows x64 和 Windows ARM64。

- 「文字翻译 → 翻译风格」新增四个提示词预设。IG / Discord 聊天为默认风格，另外提供数学、医疗和金融预设。可以编辑提示词并另存为自建预设。将鼠标移到自建预设右侧，点击 ×，再保存更改即可删除。
- 预设同时用于实时字幕和输入文字的翻译。已在监听时，保存预设后重新开始监听即可加载新风格。
- 豆包实时识别新增可选的说话人标签。开启「语音识别 → 区分说话人」后，工作台和悬浮窗可在定稿字幕上显示说话人编号。
- 改进字幕译文校验。翻译服务返回解释、对话式回答或错误语种时，程序会尝试重译，源字幕仍可继续显示。

设置位置与用法见[服务配置](../guides/services.md)。
