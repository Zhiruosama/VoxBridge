# VoxBridge 0.6.2 测试版

适用于 Apple Silicon Mac、Windows x64 和 Windows ARM64。

- 语音识别新增「豆包流式语音识别 2.0」预设，可用于中英文应用字幕、麦克风录音和短 WAV 验证。
- 豆包在说话时显示临时原文，句末进行二遍识别，再把定稿交给翻译。
- 已保存官方实时地址和 2.0 资源 ID 的待配置豆包条目会自动识别协议，并继续使用原来保存的 API Key。

使用方式见[豆包流式语音识别](../guides/services.md#豆包流式语音识别-20)。

**验证范围**：发布流水线对 macOS、Windows x64 和 Windows ARM64 运行自动化测试、构建并校验安装包。豆包实时识别在 macOS 上用中英文音频验证。Windows 的真实通话和音频硬件兼容性仍待实机验证。
