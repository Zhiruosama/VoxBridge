# 使用指南

[Руководство на русском](ru/user-guide.md)

[文档中心](README.md) · [项目首页](../README.md) · [English](../README.en.md) · [日本語](../README.ja.md)

按你现在要做的事选择一篇即可。第一次使用建议从安装和服务配置开始，其余指南可以随用随查。

## 平台与安装

支持范围、下载文件和升级步骤见[开始使用](guides/getting-started.md)。Windows 驱动、覆盖安装和卸载见 [Windows 安装指南](windows-installation.md)。具体安装包的限制见[发布说明](https://github.com/Zhiruosama/VoxBridge/releases)。

## 服务配置

按功能配置语音识别、文字翻译、语音合成。只翻译文字无需配置全部服务。[查看服务、密钥、模型和音色设置](guides/services.md)。

## 文本翻译

输入文字、选择目标语言，Enter 翻译，Shift + Enter 换行。支持复制、取消、重试与分栏调整。[查看文本翻译指南](guides/text-translation.md)。

## 应用声音与悬浮字幕

选择应用声音，显示原文和译文；浮窗可以在其他窗口上方阅读。[查看监听与悬浮字幕](guides/listening.md)。

## 文字与麦克风输入

打字或录音，确认后生成语音。设置发送设备、试听和队列操作见[语音输入与虚拟麦克风](guides/voice-output.md)。

## 接入 Discord

Mac 使用 VoxBridge 输入/输出端点，Windows 发送到 CABLE Input、聊天软件接收 CABLE Output。[查看具体路由和测试步骤](guides/voice-output.md#在-discord-中检查)。

## 外观与操作偏好

主题、界面语言、字体大小、字幕颜色、窗口宽度和不透明度见[外观指南](guides/appearance.md)。

## 常见问题

无声、权限、设备枚举、密钥和翻译报错，先看[排错指南](guides/troubleshooting.md)。需要反馈时导出[诊断日志](diagnostics.md)。

## 数据与密钥

服务配置和密钥保存于本机；文字或音频请求发给你选择的模型供应商。草稿、译文和队列不保存为长期历史。更多说明见[服务配置](guides/services.md#数据与费用)及[保存与隐私](guides/troubleshooting.md#保存更新与隐私)。
