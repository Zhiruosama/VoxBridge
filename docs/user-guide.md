# VoxBridge 使用指南

[返回首页](../README.md) · [English introduction](../README.en.md) · [日本語の紹介](../README.ja.md)

本指南介绍当前主分支的使用方式。已发布安装包的具体功能与限制，以对应的 [Release 说明](https://github.com/Zhiruosama/VoxBridge/releases)为准。

## 界面语言

在「设置 → 常规 → 外观 → 界面语言」选择中文或 English，点击「保存更改」后下次启动继续使用。主窗口与悬浮窗同步切换；界面语言不改变识别语言、翻译目标、字幕内容、草稿或自定义预设名称。此功能从 0.2.0 起提供。

## 侧栏宽度

左右拖动侧栏与内容区之间的边界即可调整宽度，松开后自动保存，下次启动保留；双击边界恢复默认宽度。也可用 Tab 聚焦边界后按左右方向键微调，Home / End 调至当前允许的最小 / 最大宽度。窗口变窄时会限制侧栏宽度，保证内容区可用；收起后再展开会保留原宽度。此功能从 0.2.1 起提供。

## 字幕段落间距

在「设置 → 常规 → 外观 → 字幕段落间距」调整主窗口两条字幕之间的留白（8–64 px，默认 26 px），保存后重启保留。悬浮字幕的行距仍在「悬浮字幕」中独立设置。此选项从 0.2.0 起提供。

## 服务配置

打开设置，分别进入「语音识别」「文字翻译」「语音合成」。选择已有配置或新增配置，填写服务地址、模型及自己的 API Key，分别保存密钥和配置更改。

| 功能     | 已接入的服务或接口                             | 何时需要                     |
| -------- | ---------------------------------------------- | ---------------------------- |
| 语音识别 | Qwen 实时 WebSocket、Qwen HTTP 短音频          | 监听应用声音、麦克风语音输入 |
| 文字翻译 | OpenAI 兼容 Chat Completions，含 DeepSeek 预设 | 翻译字幕或输入内容           |
| 语音合成 | MiniMax WebSocket、OpenAI 兼容 Speech          | 本地试听或通过虚拟麦克风发声 |

预设用于帮助填写配置，不附带密钥、额度或私人克隆音色。兼容服务必须支持对应协议，不能仅凭 API Key 通用。接口细节见[服务配置与兼容边界](08-provider-configuration.md)。

主分支设置页的「模型」「音色」使用单一选择控件，选择「手动输入…」可填写自定义标识，回车确认、Esc 取消。较早安装包可能仍分别显示预设下拉框和输入框。

在「自定义预设」中可保存常用名称与模型或音色标识，完成后点击「保存更改」。每类最多 50 条，按服务配置与协议分别保存；同一服务共用密钥。删除预设不删除服务或密钥，也不会改变当前所选标识。删除整个服务配置则会同时移除该配置的密钥。

### 语言、音色和语速

- 监听语音默认自动识别。指定识别语言、修改字幕语言：设置 → 常规 → 监听字幕。
- 输入框旁的语言选择控制发出的语音目标语言，与字幕语言独立。
- 当前提供中文、英语、日语、韩语、西班牙语、印尼语、粤语、芬兰语、俄语和德语；识别与合成能力仍取决于服务和模型。
- 本地能够确认输入与目标语言相同时，直接合成原文；混合语言或识别不确定时按正常流程翻译。书面粤语与普通话不能可靠地仅凭文字区分，粤语仍按翻译流程处理。
- 输入框底部的音色入口支持切换已配置的语音服务、模型、音色与语速。监听期间也能调整，下一次生成生效，正在播放的内容保持原配置。
- MiniMax 的目标语言会映射到 `language_boost`，例如粤语 `Chinese,Yue`、芬兰语 `Finnish`、俄语 `Russian`、德语 `German`。自定义或克隆音色的口音效果需要实际试听。

文字翻译设置中可调整翻译风格；0.2.0 起名称为「翻译风格」（0.1.0 中为「前置 Prompt」）。默认偏向适合 Discord、Instagram 聊天的自然口语。风格用于字幕和输入翻译，目标语言仍由语言设置决定。

## 应用声音与悬浮字幕

让目标应用播放声音，选择应用后开始监听。应用未出现时重新展开列表，或在设置 → 常规 → 音频中刷新应用。

原文和译文显示在工作台，点击「悬浮字幕」可在其他窗口上方阅读。浮窗可跟随 macOS 桌面与全屏空间，支持连续阅读、双语 / 原文 / 译文显示，以及字号、行距、颜色和透明度调整。

设置 → 常规中可以分别设置识别内容和主动输入内容的颜色。悬浮窗默认同步工作台，也可以在悬浮字幕的配色来源中选择单独设置。

隐藏浮窗不停止监听；点击停止监听才结束采集。关闭主窗口会退出应用并停止任务，黄色窗口按钮用于最小化。

## 文字与麦克风输入

- **Enter**：默认翻译后输出语音，可在设置中修改。
- **Shift + Enter**：换行。
- **翻译按钮**：只翻译，结果显示在字幕区。
- **原文 / 译文**：决定语音合成使用哪份文字。
- **耳机按钮**：控制是否在本地试听，不影响发送。

点击麦克风开始录音，再点击结束，最长 1 分钟，支持取消。默认先把识别结果放进输入框，确认或修改后发送；开启「直接发送」后，录音结束会自动识别、翻译并合成语音。如果录音期间修改过草稿，会先等待确认，避免误发。

在设置 → 常规 → 音频 → 语音输入麦克风中选择实体麦克风，默认跟随系统输入。麦克风语音经过识别和重新合成，不直接转发原始录音。

悬浮窗右下角也支持麦克风和键盘输入。输入框只在主动展开时出现，收起会保留草稿。主窗口和浮窗共用语音任务与发送队列。

## 发送队列与试听

发送后输入框清空，输出期间可以继续编辑并发送下一条。队列最多保留 10 条，翻译与语音准备可以并行，声音始终按提交顺序播放。

点击队列入口可暂停、继续、编辑、重试或取消。停止当前输出会暂停后续队列；失败项保留原文，先重试或取消失败项，再继续发送。每条消息使用提交时的配置，修改或重试可能重新调用计费服务。队列只保留在本次运行期间，退出软件会取消。

发送与试听使用同一份合成结果。试听开关可在播放时切换，不重新合成；中途开启只播放后续部分。主分支已支持将试听输出设为「系统默认」，每次开始播放时读取当前系统输出。

## 接入 Discord

1. 先结束通话，在设置 → 常规 → 音频中安装虚拟麦克风。管理员授权由系统安装器申请，安装时会重启系统音频服务。
2. 刷新设备，将发送设备设为 VoxBridge，试听设备设为耳机或系统默认。不要把 VoxBridge 设为系统默认扬声器。
3. Discord 输入设备选择 VoxBridge，输出设备仍选择耳机或扬声器。名称后的 `(Virtual)` 是 Discord 的设备类型标注。
4. 使用 Discord 麦克风调试时，可先关闭 VoxBridge 自身试听，避免重复听到两路声音。
5. 若声音断续，试用 Discord 的「工作室」输入配置，排除降噪和回音抵消的影响。正式通话前关闭麦克风调试。

**发送设备决定对方收到什么，试听设备决定自己听到什么。** 发送设备选成耳机时，声音不会进入虚拟麦克风。

## 诊断日志

遇到问题时，可在「设置 → 音频与诊断 → 本机诊断日志」导出日志，结合报错截图和发生时间反馈。日志仅在本机保存，自动轮转，不记录密钥、录音、字幕或输入正文。操作说明和字段含义见[诊断日志文档](diagnostics.md)。此功能尚未包含在已发布的 0.2.1 安装包中。

## 常见问题

**首次打开被 macOS 拦截？** 当前测试版未公证。确认下载来自本仓库后，按[发布说明](releases/v0.2.1.md)和 [Apple 指引](https://support.apple.com/zh-cn/102445)操作，无需关闭系统整体安全保护。

**为什么又要求音频权限？** 系统音频录制与实体麦克风是不同权限。临时签名的开发版重新打包后，系统可能重新确认授权。0.2.0 已将设置页的设备查询改为只读属性查询，主动录音时才申请麦克风授权。

**耳机断开后无声？** 试听设备选择「系统默认」，或刷新后重新选择。显式绑定某个设备时，设备断开不会擅自换到另一个设备。

**Discord 看不到 VoxBridge？** 确认已安装驱动，刷新设备；仍未出现时完全退出再打开 Chrome。软件需要取得相应的麦克风权限。

**QQ、微信可以用吗？** 兼容性仍在排查。QQ 曾在本机临时兼容设备与完整重启后列出该设备，但这个临时方案未包含在发布包中；不能据此保证普通安装可用。见 [issue #1](https://github.com/Zhiruosama/VoxBridge/issues/1) 与[微信调查](wechat-virtual-microphone-investigation.md)。

**翻译失败后不继续发送？** 为保持输出顺序，失败项会暂停队列。检查服务配置和目标语言，重试或取消失败项后继续。主分支包含更明确的错误信息，历史安装包行为可能不同。

## 数据与密钥

API Key 保存后，重启自动恢复，不需要重新载入模板。密钥与普通设置分开存储，正常使用不访问系统钥匙串。移除密钥后不会在重启时自动恢复旧密钥。存储边界见[密钥持久化说明](validation/2026-10-24-private-credentials.md)。

应用声音或录音会发送给所选识别服务，识别文字交给翻译服务，待合成文字交给语音服务。常规运行不自动保存原始音频或字幕历史；明确执行的开发录音诊断除外。云服务费用由相应供应商收取。
