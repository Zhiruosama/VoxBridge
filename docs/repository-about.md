仅修改 Description，保留现有网站地址和 Topics。README 的代码改动需要合并到默认分支，仓库首页才会显示；About 是独立的仓库元数据，不会随分支提交自动更新。

可在仓库首页 About 的编辑入口修改，或在已经通过 `gh auth login` 登录的环境执行：
