# 桌面应用单实例

Windows 和 Mac 普通启动在其他插件、配置和音频初始化之前注册 Tauri 官方 single-instance 插件。再次启动时仅恢复原主窗口：显示、解除最小化并聚焦，不重建 WebView、队列或监听任务。锁使用应用标识，与可执行文件所在目录无关。

Windows 托盘和 Mac Dock Reopen 共用同一窗口恢复函数。安装、卸载和更新参数入口跳过单实例插件，维护界面可以独立运行；它们原有的运行中应用检查仍生效。

隔离回归程序 `src-tauri/examples/single-instance-regression.rs` 使用独立应用标识，不读取用户配置、密钥或音频设备：先创建隐藏主窗口，启动维护进程，再启动第二个普通进程，验证维护入口可启动、已有窗口可恢复以及第二个进程退出。

Windows 本机可验证进程间通信；Mac 共享接入代码仍需在 Mac 上编译和实机验证。已运行的旧版本不包含单实例锁，首次使用此修复需要先退出旧进程。

Windows 验证：Rust 180 项测试通过，25 项环境相关测试忽略；隔离进程测试退出码为 0，确认维护进程可并行启动、第二个普通进程唤起已有隐藏窗口。文档检查及 Rust 格式检查通过。测试不读取用户配置或执行真实安装，未覆盖本机安装版。
