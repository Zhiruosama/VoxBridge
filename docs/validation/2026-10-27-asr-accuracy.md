# ASR 纠正、短回答与音频诊断

[验证索引](README.md) · [内部流程](../internal-flows.md) · [诊断说明](../diagnostics.md)

## 本轮范围

根据离线调研复现结果调整生产流水线，没有更换用户模型，没有发起付费服务请求或录制用户声音。

- 供应商最终结果可纠正当前识别段最近八条本地字幕：保留字幕 ID、时间、顺序和段落身份，提升修订号，清除旧译文并重新翻译；撤回的内容删除。临时修订不重复回写已提交字幕，上个供应商识别段不回溯。
- 翻译任务用共享源修订标记识别过期工作。排队任务过期后不启动请求；在途过期结果及错误丢弃。已在途请求不会因纠正自动撤销计费，并发仍最多三个。
- 既有指定识别语言设置映射到千问实时 3.0 / 3.1 的语言提示；自动识别维持原行为，自定义模型不假设支持额外字段。3.1 的粤语使用保留方言选项。依据为[官方客户端事件协议](https://help.aliyun.com/zh/model-studio/qwen-audio-asr-streaming-client-events)，核对日期 2026-10-27；字段正确不等于真实模型已通过语言质量评测。
- HTTP 短音频过滤从至少 300 ms 有效声音改为 120 ms；保留前后音频缓冲、静音与极短点击过滤。WebSocket 不受此门限影响。
- 音频计量新增实际下混电平、接近满幅帧数、下混低电平窗口数。窗口至少 320 帧、原始 RMS 不低于 0.008，单声道 RMS 小于原始十分之一时累计提示；不自动改变音频信号。
- 统计只显示于监听详情，并以有界、限频的数值记录日志，不保存识别文本、波形或热词。

## 自动验证

- 复现 `fifteen dollars` → `fifty dollars`，包括中间临时修订、重复最终结果、被撤回尾部、八条边界与跨供应商段隔离。
- 旧翻译成功、失败与错误提示不能覆盖新修订；停止会话后拒绝迟到纠正，段落和位置保持。
- 本地模拟翻译验证在途旧错误被丢弃、过期排队任务不发起请求，后续纠正正常完成；沿用并发与取消回归。
- 16 / 48 kHz 合成音频验证：200 / 400 ms 有效信号各产出一个合法 WAV，0 / 20 / 80 ms 不产出；这不是人类短语识别准确率测试。
- 同相 / 反相双声道验证下混电平和疑似抵消计量；近满幅帧按帧计数，空窗口不继承旧电平，计量不修改源帧。
- 语言提示测试覆盖自动、指定英语 / 葡萄牙语 / 日语、粤语模型能力区分、未知模型和未支持提示语言。
- 日志测试验证数值采样限频及不记录任意事件附加内容。中英界面翻译键检查随前端测试运行。

验证结果：243 项前端测试、165 项 Rust 测试通过；23 项依赖真实设备或付费服务的手动测试未运行。格式、前端构建、文档链接检查及 macOS App 打包、签名与麦克风 entitlement 检查通过。原调研的离线回放在当前生产代码上显示最终字幕为 `The price is fifty dollars.`，200 ms / 400 ms 合成音均产生一个 HTTP 分段。

## 验证边界与后续

本轮验证针对本地逻辑、协议正文与回归，不声明真实语音 WER、葡萄牙语质量或云端延迟已改善。尚未进行 Windows 实机及用户素材对照。短声音门限可能增加噪音触发和 HTTP 请求，需要真实录音 A/B 后再判断。

ASR 热词、自动领域上下文、VAD 或降噪继续独立评估：不将错误识别文本无条件作为高权重热词，不把启动任务时的上下文当作流中可随时更新的参数，不为了注入上下文频繁重连。
