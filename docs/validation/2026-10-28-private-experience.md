# 私下体验安装包与公共外观默认值

用户明确授权使用当前三组活动服务配置与密钥制作私下体验包。真实值、编译中间文件与安装包仅存于忽略目录或仓库外，不进入 Git 或公开发布。

- 只有显式设置 `VOXBRIDGE_PRIVATE_PRESET` 的本机构建包含预设，CI 拒绝该入口；普通构建重新写入空预设。
- 主窗口首次启动，在没有当前配置、备份或损坏记录时导入。先校验设置，再将缺失凭据写入安装用户的本机加密存储，最后保存设置。已有配置或凭据不覆盖。密钥不返回前端，不写诊断日志。
- 预设保留活动服务、模型、音色、语速、语言、主题、字号、颜色、间距、透明度与其他 Settings 偏好；发送自动选择虚拟麦克风，试听跟随系统默认，不携带制作者的实体设备 ID。
- 独立原生测试使用临时应用标识，验证首次导入、原生读取与重复导入不覆盖已有密钥，未调用模型服务。前端验证旧配置/备份/损坏记录保护、导入顺序与失败不保存设置。
- 安装包内密钥可被提取。仅由用户私下提供给可信朋友，后续分发建议使用独立限额密钥或服务端中转。

按用户要求，公共外观默认值同时更新为：深色、工作台字幕 17px、识别黄色/输入白色、段落间距 15px；字幕浮窗 16px、行距 1.3、不透明度 59%；文本浮窗保持 17px、行距 1.7、不透明度 90%，文本面板不透明度 85%。已保存外观不重写，公共包不含服务密钥或个人配置。

用户自行卸载/安装测试前已在本机恢复目录备份完整 Local Storage 与加密凭据。普通卸载默认保留数据；新用户导入测试需用户主动选择清除应用数据。此轮没有代用户卸载或清空配置。

验证：297 项前端测试、173 项 Windows Rust 测试通过（25 项忽略，不计作通过）。私有构建下独立原生导入回归通过，使用隔离标识，不访问用户的正常配置。外观默认值回归确认显式保存过的旧外观保持原样。
