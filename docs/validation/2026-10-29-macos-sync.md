# Windows 更新后的 Mac 同步检查

同步 `bcb1100` 后，在 Apple Silicon Mac 检查共享功能与平台边界。

## 已对齐的内容

- 自动更新开关、签名包下载、忙碌等待、5 秒倒计时、推迟与草稿恢复均为共享实现，Mac 使用同一状态机；开关默认关闭。
- 字幕外观默认值与首次私下体验配置导入为共享实现。已保存的用户设置不会被默认值覆盖；公开构建不设置私有预设环境变量，不导入私人服务或密钥。
- Windows 系统托盘、安装及卸载器保持 Windows 专用。Mac 仍使用红色按钮隐藏、Dock 恢复、⌘Q 真正退出，以及原生标题栏和缩放逻辑。

## 本次补齐

自动安装原先只检查任务、设置和输入草稿，没有阻止空白剪贴板监听会话被重启打断。现在剪贴板监听开启期间，即使尚未复制文字，也会等待；监听重新开始会重置安装倒计时。停止监听后仍有草稿时继续等待。手动更新保留原有的暂存草稿、停止剪贴板监听再安装逻辑。

此修复同时适用于 Mac 和 Windows，不修改监听偏好或扩大自动更新范围。

## 验证

- 300 项前端测试通过，包括空白剪贴板监听阻止自动安装、监听重启重置倒计时、草稿保护，以及手动更新顺序。
- Mac 默认 Rust 测试 175 项通过，23 项依赖设备或外部服务的测试忽略，不计作通过。
- 文档链接、前端格式、版本元数据与 Mac 生产构建检查通过；应用签名、麦克风 entitlement 和用途声明检查通过。
- 更新本机 `/Applications/VoxBridge.app`，保留用户配置与凭据，不自动重启应用。

本轮没有安装真实在线更新、重新安装音频驱动、调用付费服务或代用户通话。Windows 安装器与托盘不在本机实测范围内。
