# Windows 关闭到系统托盘

沿用 `mainWindowCloseBehavior: hide` 偏好，Windows 从任务栏最小化调整为隐藏主窗口，在系统托盘保留恢复入口；Mac 保持原有隐藏逻辑。已有配置无需改写。

- 正常应用创建托盘图标，安装与卸载界面不会创建。左键点击/双击恢复主窗口，右键提供打开及退出菜单；退出调用既有任务清理流程。
- 选择「退出应用」仍真正退出。顶部最小化按钮保留任务栏最小化行为。
- 只有托盘成功注册后才允许隐藏 Windows 主窗口；初始化失败则回退到任务栏，避免失去恢复入口。Windows 决定图标是否位于溢出箭头内，不改系统托盘偏好。
- 不修改系统默认音频设备，不访问真实音频或调用模型服务。

验证包括关闭策略的三项原生测试，以及独立 `windows-tray-regression`：使用独立 WebView 目录创建真实托盘，核对托盘持续存在、主窗隐藏与恢复显示/取消最小化。普通和私下体验安装包均需重建以携带新托盘代码。

结果：298 项前端测试通过，三项关闭策略测试通过，最终原生托盘回归通过。托盘图标使用编译期 PNG 资产，避免宿主没有可读默认窗口图标时失败。托盘特性仅在 Windows 依赖中启用。普通包及私下体验包均已重建，本机覆盖更新并启动；设置记录逐字节一致、凭据文件一致。未在真实用户会话中调用音频服务或进行长期后台任务验证。
