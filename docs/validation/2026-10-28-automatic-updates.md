# 自动更新偏好与安装流程

- 新增共享前端设置 `automaticUpdates`，缺省为关闭，旧配置无需迁移写入。开关只保存该偏好，不提交其他未保存设置。
- 启用后启动检查、下载并校验签名；等待监听、录音、发送队列、剪贴板监听、文字翻译和草稿结束，再倒计时 5 秒安装重启。新任务会重置倒计时。
- 「稍后」只推迟本次运行；关闭自动更新会停止倒计时。已下载包可复用，保留手动检查与安装。
- 增加阶段文字过渡、下载进度、安装指示与提示退出动画；支持 reduced motion。

验证：前端 283 项测试及生产构建通过，Windows debug NSIS 安装包构建通过。覆盖自动下载与重启、忙碌等待及倒计时重置、下载中关闭、稍后推迟、签名失败不安装、旧配置默认值等场景。独立本地预览复用正式控件与状态机，以模拟传输验证交互，不安装真实更新。当前本机与公开版本均为 0.5.2，真实跨版本安装需下一次签名发布后再验证；此变更未发布新版本。

已覆盖安装到本机并重新启动，在「设置 → 常规 → 关于」确认开关与最新版本状态显示正常。安装前后 Local Storage 中设置记录逐字节一致，两个凭据文件 SHA-256 一致。演示中已观察到下载进度、忙碌等待、解除忙碌后倒计时以及模拟重启完成。
