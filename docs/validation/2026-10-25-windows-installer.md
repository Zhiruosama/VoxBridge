## 结构

单文件 EXE 外层只解包临时安装文件。正常交互启动应用自身的 `setup` 窗口，复用 React、字体和主题样式；窗口不初始化凭据，不打开音频，也不检查模型服务。确认安装后调用已有 NSIS 引擎执行文件、注册表和快捷方式操作。安装完成后可打开应用。

安装窗口使用独立 capability，仅允许安装信息、目录选择、开始安装及完成操作，不具有主窗口的凭据、采集、发送或更新权限。安装时禁止再次提交或关闭；路径校验拒绝磁盘根目录、网络路径、控制字符与引号，`/D` 使用 NSIS 要求的最后一个参数格式。底层安装引擎使用命名互斥量拒绝同时安装。

已有应用走 `/UPDATE`，保留原标识、配置与凭据目录。VB-CABLE 不在更新时安装或卸载；首次安装可勾选，取消驱动安装只提示，不回滚已安装的应用。

外层收到 `/S` 或 `/P` 时直接转交 NSIS，保留更新器的无人值守路径。没有 WebView2 时原生兼容向导负责前置运行环境与安装。卸载器仍使用原生引擎。

## 打包与签名

`npm run desktop:build:windows` 先生成 NSIS 内层安装器，再把应用安装界面及内层安装器封装成同名 EXE。开启 updater 产物时，删除内层签名并对最终外层 EXE 重新签名，签名可信注释绑定应用版本。只分发最终外层包；不分发临时预览或裸界面程序。

品牌 BMP 已提交，`installer-artwork/render.py` 仅用于开发时重新生成，CI 无需 Pillow 或系统字体依赖。安装界面截图曾在本机展示并经用户确认；发布前另验证实际安装、静默更新、凭据保留及最终包签名。
