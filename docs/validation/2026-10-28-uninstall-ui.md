# Windows 卸载界面统一

旧卸载器仍使用原生 MUI 固定布局，深色着色叠加后出现标题重叠、边距和内容区割裂。交互卸载改为与安装器共用 React / WebView2 外壳样式、字号、卡片、步骤导航及窗口按钮。

- `uninstall.exe` 的确认页前置回调将应用和原卸载引擎复制到 NSIS 临时目录，运行专用卸载界面。取消仅关闭界面，不进入原卸载流程。
- 用户明确点击卸载后，委托原 NSIS 引擎执行；升级 `/UPDATE`、静默 `/S` 与被动模式不进入交互外壳。
- 清除个人配置与密钥、打开官方驱动管理器默认均关闭。仅显式选择清除数据才传入对应选项；驱动仍由官方管理器处理。
- 卸载路径只接受与当前用户注册安装位置一致的有效本地目录；引擎缺失、路径不匹配或正常应用仍在运行时拒绝执行，不强制终止用户工作。
- 安装/卸载专用窗口无音频、服务密钥和私人预设导入权限。

验证范围：前端 297 项测试通过，原生安装路径与参数注入校验测试通过，正式前端/Windows 安装包构建。卸载预览只读取安装信息，不执行移除或清除数据；真实文件及数据删除链路由用户随后自行验收。

本机覆盖更新后，从真实安装目录 `uninstall.exe` 打开新版界面，中英文长文案均完成截图检查，卡片与按钮无重叠。点击取消后 UI 与外层卸载器退出，应用文件仍在；未触发卸载、清除配置或驱动操作。朋友体验 EXE 同步重建，不公开发布。
