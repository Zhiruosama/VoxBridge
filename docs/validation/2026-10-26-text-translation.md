# 独立文本翻译页面验证

- 入口：主导航「字幕」下方的「文本翻译」。在同一主窗口切页，不创建额外的系统窗口。
- 只复用文字翻译服务及前置 Prompt；控制器依赖仅有 `translate` / `cancelTranslation`，没有 ASR、TTS、录音或音频路由依赖。
- 原文、语言选择和最近译文保存在 App 持有的会话控制器中。切页不会清空，不写入持久化历史或日志；退出软件后释放。
- 原文默认自动识别，目标语言独立选择。翻译采用提交时的文本、目标语言和配置快照；请求期间继续编辑不会修改进行中的请求，也不会清空新草稿。
- 支持取消、清空、复制和 Cmd/Ctrl + Enter；每次最多 2000 个 Unicode 字符，与后端限制一致。

## 布局与聚焦样式复查

后续调整让双栏随可用高度延展，底部仅保留正常页面内边距；窄内容区仍上下排列并在主内容区滚动。移除原文输入框的手动高度拖动，避免与自动高度冲突。卡片及聚焦样式复用主输入框的主题阴影变量，聚焦不再使用实色深边线，并尊重减少动态效果偏好。已在中文浅色/深色宽布局、英文 680px 内容容器中检查空状态、输入聚焦、按钮位置与堆叠显示；TypeScript / Vite、Prettier 和 macOS 打包签名检查通过。

## 背景不透明度与双栏比例

- 分隔条通过指针捕获调整 30–70% 比例，拖动结束记入独立布局存储；支持方向键、Home/End、双击等宽。上下排列时隐藏分隔条，比例设置不丢失。

- 中文浅色宽布局、英文深色 680px 内容容器的堆叠与分隔条隐藏均检查通过。

## 轻阴影与 Enter 提交复查

- 去掉聚焦状态的 3px 光圈和加深边线。面板表面独立渲染，使用低强度边线与扩散阴影，输入聚焦不再改变边缘粗细。
- 此前背景 alpha 已正确保存与渲染，但浅色面板与页面底色接近，视觉差异很小；现在不透明度控制背景、边线及阴影整体，文字和操作控件保持 opacity 1。在设置保存 0% 后，实际表面 opacity 为 0，截图中面板背景与阴影均消失，文字与按钮仍在；恢复 85% 后表面恢复。
- Enter 提交文字翻译，Shift + Enter 换行，保留 Cmd/Ctrl + Enter。重复按键不重复提交，输入法组合状态及 Safari keyCode 229 不提交。
- 本地模拟桥接实际按 Enter 出现译文；Shift + Enter 后新增一行，译文保持上一次结果。新增键盘规则测试，206 项前端测试通过；TypeScript / Vite、Prettier、macOS 打包签名检查通过。
