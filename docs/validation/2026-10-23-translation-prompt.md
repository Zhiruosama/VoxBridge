2026-10-23：设置 → 文字翻译增加前置 Prompt 编辑区及“恢复默认”。Prompt 随当前翻译服务配置保存，最多 4000 个 Unicode 字符，空白时使用默认值。新增配置、内置 DeepSeek 预设及缺少此字段的旧配置均采用新的口语化默认值；已有自定义值不被预设切换或重新加载覆盖。

默认内容适合 Instagram 私信、Discord 文字聊天和语音交流：自然简洁、允许常见英文缩写，保留说话者语气、否定、姓名、金额、时间等信息，不擅加亲昵称呼、俚语、表情或背景，只输出译文。共享源文件为 src/core/default-translation-prompt.txt，前端 raw 导入与 Rust include_str 使用同一份内容。

## 请求链路

- ProviderProfile 增加 translationPrompt，普通设置通过 parseSettings 保存白名单字段；仅翻译配置保留此字段。
- 输入翻译及监听翻译均把自定义提示放在 system 消息的最前面，随后附加目标语言、只翻译不回答等任务规则。用户编辑的是表达风格；目标语言仍由界面语言设置决定。
- 原文始终放在 user 消息。监听上下文继续使用 previousCaptions/currentText 的 JSON 隔离，不拼进 system 提示，不让上下文成为自定义指令。
- 译文无效的重试和暂时故障的重试继续沿用相同 Prompt。监听会话持有当前配置快照，不随在途草稿变化。
- 修改 Prompt 不读取 Keychain、不解锁或保存凭据模板，不改变原有一次会话授权限制。
