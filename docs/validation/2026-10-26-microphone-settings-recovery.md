# 麦克风选择与设置保护

[验证索引](README.md) · [语音输出](../guides/voice-output.md)

## 问题与处理

用户反馈实体麦克风拒绝提示及配置看似丢失。先备份本机 WebView Local Storage 与加密凭据，再进行源码与只读设备检查，没有用默认值重建服务配置。

本机旧记录仍包含三套完整服务配置，当前解析器能够正常解析，三份密钥也可由原有 DPAPI 凭据存储读取。已保存输入 ID 指向 Realtek 麦克风阵列，当前系统默认也是该设备；只读解析通过。本轮没有复现该实体端点被当前筛选逻辑拒绝，不能据此宣称已确认用户报错的唯一触发原因或配置被删除的原因。

代码审计补齐以下边界：

- Windows 只按确认的 VB-CABLE 回送端点排除自身输入，不因实体麦克风的自定义名称包含 VoxBridge 就拒绝。
- 自动输入优先有效的系统默认麦克风；系统默认为自身回送端点时，从可用安全输入选择，避免默认设置直接报错。用户明确指定的设备断开或为自身回送时仍提示，不自动改录其他设备。
- 开始 ASR 连接前先解析并固定麦克风稳定 ID，录音前再次核对；不因麦克风无效而先启动收费识别流。
- 保存设置前保留上一份有效记录，首次保存也创建备份。读取时原记录损坏或缺失可读备份；损坏原文另行保留。备份写入失败时不覆盖当前主记录；不向日志输出配置或密钥。

## 验证

- 230 项前端测试、155 项 Rust 默认测试、严格 Clippy、格式和前端构建通过；24 项手动测试未计入默认通过项。
- 单独只读测试：两个可选输入的完整名称、稳定 ID 和录音前解析通过；本机默认 Realtek 输入通过检查。
- 模拟系统默认指向回送端点、明确选择回送/断开设备、没有安全输入，以及设置损坏恢复和备份写入失败的保护回归通过。
- 未录制用户声音、未调用云识别；这些检查不能代替实际录音与通话验收。
