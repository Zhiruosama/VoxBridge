# 上下文语气：实现与验证

本次在 `codex/contextual-speech-prosody` 分支实现，未修改 main。

## 行为

- 「设置 → 常规 → 文字表达 → 上下文语气」默认关闭。MiniMax 的译文语音启用后，由当前文字翻译服务在同次 Chat Completions 请求中返回译文、情绪和相对语速。纯文本翻译与原文直出保持原路径。
- 上下文是本次运行中最近 60 秒的已确认监听原文，以及已开始播放发送的本地原文；最多 12 条、4000 字符，单条截取最多 1200 字符。`self` / `remote` 只区分本地与混合远端音频，不识别具体参与者。
- 入队前固定上下文，队列和控制器再复制快照；未来纠错、后续发言不会改变已提交任务。ASR 最终纠错按段 ID 替换旧文本。开始新监听会话、退出程序时清空，不进入设置、草稿恢复文件或诊断日志。
- 请求使用 `response_format: json_object`，上下文只作为 user 角色中的引用数据。返回字段由后端重新构造并验证译文。无效语气字段降为 auto / 1.0；结构无效、空内容或服务以 400/422 拒绝 JSON 时，仅退回一次普通翻译，仍受原取消令牌、响应大小和超时限制。
- 前端再过滤模型支持的情绪与 ±10% 相对语速，速度总范围保持 0.5–2.0。手动情绪优先，音色、音高、音量、发音字典及效果不变；自动值仅作用于本条任务。

## 验证

- 307 项前端测试通过，覆盖历史过期/修正/快照、参数边界、手动优先、同语言规划、纯翻译隔离和取消后禁止合成。
- 180 项 Rust 测试通过，23 项既有环境相关测试忽略。新增本地 HTTP 服务验证单请求协议，以及 JSON 不支持、空响应和无效结构的两次请求上限与降级路径。
- TypeScript / Vite 构建、Prettier 检查、文档链接检查通过。
- 隐藏浏览器检查英文设置入口、开关选项、未保存状态和布局；新增中文文案提供对应英语翻译。
- macOS 应用构建及签名、麦克风权限声明检查通过；本机 `/Applications/VoxBridge.app` 已替换，未强制重启。构建目录的应用副本已注销并移至废纸篓。

未请求真实付费合成，也未向服务发送当前聊天历史。本次验证证明数据流与降级行为，语气自然度仍需使用相同音色、语速和文本做开启/关闭的实际试听对照。
