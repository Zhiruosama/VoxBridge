# Mac 原生标题栏主题过渡

[验证索引](README.md) · [外观设置](../guides/appearance.md)

## 修复

页面原有的快照淡入淡出不包含原生标题栏。本次通过现有 Tauri 窗口接口，使 Mac 标题栏背景在 400 毫秒内平滑变化，原生文字对比度在中段切换，保留系统窗口按钮与布局。

连续切换会取消旧帧；原生调用串行执行，并记录实际应用的中间色，后续过渡从该颜色继续。初始化、颜色不变或开启减少动态效果时直接同步。Windows 不运行原生 Mac 色彩过渡，沿用页面主题动画。

## 验证

- 267 项前端测试通过，新增覆盖中间色、准确终点、取消后反向切换、原生调用进行中取消、初始化和减少动态效果。
- 原有 Mac 主题通知回归通过：显式选色不被原生媒体查询通知打断，跟随系统仍响应真实变化。
- 独立原生窗口运行生产 `useTheme`：实际读取 AppKit 窗口背景色，采样得到 45 种颜色，曾到达浅色终点，快速切换后回到深色终点，通过。窗口不加载 App、用户设置、凭据、剪贴板或云服务，完成后退出。不可见窗口不绘制动画，因此测试窗口需短暂可见，不移动用户窗口。
- 格式、前端构建、文档检查及 Mac 打包签名检查通过。

复现原生验证：先运行 `npm run dev`，再执行：

```sh
cargo run --manifest-path src-tauri/Cargo.toml --example native-theme-regression
```

测试使用本地开发服务器和临时标识 `dev.voxbridge.native-theme-regression`，不改变已安装应用的配置。原生颜色采样验证背景真实变化；最终动画观感仍可因显示器刷新率和系统负载不同而异。


## 后续修正：统一原生与页面进度

单独给原生栏插值、让页面继续快照淡出，仍会出现不同的动画起点和曲线，并在交叉淡化中把文字混成灰色。Mac 现改为原生过渡完成每一帧颜色设置后，将同一进度用于页面背景、侧栏、面板、边缘和阴影；文字在中段切换清晰的前景色，不再参与整页交叉淡化。Windows 保留已有页面动画。

快速切换读取当前可见调色板作为起点，正常完成或卸载后恢复原有样式，避免残留临时变量。初始化与减少动态效果仍不播放动画。

- 270 项前端测试通过，新增覆盖统一的页面颜色进度、清晰文字端点、反向切换连续性、样式清理和 Windows 路径。
- 独立 Mac 原生窗口的实际采样：89 次 DOM/AppKit 色彩比对最大 RGB 差为 0；采到 40 种原生背景色，准确到达浅色与深色终点；同时确认没有旧页面快照、前景色保持端点颜色。
- 格式、文档检查、前端构建、Mac 打包与签名检查通过。颜色比对验证原生属性与页面样式同步，不等同于所有显示器下的逐像素视频验收。

## 后续修正：顶部背景与页面共用合成层

实际体验仍出现分层：先前的采样比较 AppKit 背景属性和 DOM 样式，并没有覆盖两条渲染管线最终显示的时机。数值相同不足以证明显示帧一致。

Mac 主窗口现使用 `TitleBarStyle::Overlay`，由同一个 WebView 绘制顶部背景与应用标题，保留系统原生红黄绿按钮。顶部预留 32 个逻辑像素、按钮位置固定，背景与侧栏使用同一主题变量。主题切换复用整页 View Transition 或兼容快照，不再逐帧修改 AppKit 背景和页面颜色变量；AppKit 只同步最终外观设置。Windows 的窗口按钮与布局保持原有实现。

验证使用独立测试窗口，不读取用户设置或凭据：

- 生产主题钩子及 Mac 顶部组件参与测试，706 帧检查均保持同色背景、文字颜色、完整标题栏宽度和 32px 预留高度；到达深浅两端，包含快速反向切换。
- 原生窗口确认 FullSizeContentView、隐藏原生标题和透明标题栏同时启用。
- 通过窗口截图采样实际显示结果：8 张截图中包含中间色帧，在顶部与页面的同色背景区域逐张比较，RGB 最大差为 0。这是选定采样点的检查，不代表所有显示器和场景的完整视觉验收。
- 原生窗口缩放按钮操作正常；点击系统全屏按钮后进入全屏，使用 Control + Command + F 退出后关闭、最小化与全屏按钮恢复。

自动验证仍使用上面的 `native-theme-regression` 命令；设置 `VOXBRIDGE_THEME_VISUAL=1` 可将窗口保留 60 秒，方便观察。旧的原生逐帧插值及逐变量页面过渡代码和对应测试已移除，主题通知、初始化、减少动态效果、取消和 Windows 共用过渡仍有测试覆盖。
