# 剪贴板翻译与独立小窗

[验证索引](README.md) · [使用方式](../guides/text-translation.md) · [内部流程](../internal-flows.md)

## 实现边界

- 监听与自动翻译均为本次运行的显式开关，默认关闭。不在启动或进入页面时读取剪贴板，不自动导入开启之前的内容，不建立剪贴板历史。
- 开启后轮询纯文字；空白、重复和自身复制不进入新请求。超出 2000 Unicode 字符提示处理，不自动截断发送。关闭和卸载使在途读取失效。
- 确认模式只替换草稿；自动模式先合并短时变化。有效新内容取消旧翻译、清除旧结果，迟到结果不会覆盖新内容。手动翻译不与待触发的自动任务重复提交。
- 文本小窗只接收译文及工作状态，提供翻译、复制、暂停监听、返回文本页和隐藏。没有 ASR/TTS、录音或凭据访问。只有主窗口被授予系统剪贴板纯文字读写权限。
- 小窗沿用透明圆角、八方向缩放和原生逻辑坐标；Mac 多浮窗使用分别持有的 NSPanel 与有效隐藏宿主。

## 验证

- 256 项前端测试通过：默认不读取、基线跳过、去重与空值、自身复制、2000 字 Unicode 边界、超长拒绝、慢读取不重叠、停止后忽略迟到读取、不可读内容后恢复、新复制内容淘汰旧结果及启动透明层。
- 169 项 Rust 测试通过，23 项设备/付费服务手动测试未运行。新测试覆盖浮窗快照/动作限制及浮窗无剪贴板、凭据和发布权限。
- 浏览器使用模拟剪贴板与模拟翻译服务操作真实组件：确认模式只填入草稿；自动模式请求一次并同步小窗；复制译文后计数仍为一次；可从小窗手动翻译与暂停；中英文界面及 560 × 300 小窗布局已检查。没有读取用户剪贴板或调用付费模型。
- [`text-overlay-regression.rs`](../../src-tauri/examples/text-overlay-regression.rs) 运行生产 NSPanel 管理与内容迁移代码，创建两个不可见测试窗口。验证重复准备、独立所有权、按标签拖动/缩放/隐藏和有效隐藏宿主；未移动用户窗口，未开启剪贴板或模型服务。
- 格式、前端构建、文档检查及 Mac App 打包、签名和麦克风 entitlement 检查通过。

## 仍需实机体验

Windows 剪贴板权限、隐藏窗口后的长时间轮询，以及 macOS 新版本的系统剪贴板访问提示需要在对应系统实测。真实剪贴板变化发生在两次轮询之间时，只会处理下一次读取到的最新文字。停止监听不会撤回已经发给供应商的请求，也不能撤销费用。本文不声明已通过真实付费翻译或完整 Windows 安装测试。
