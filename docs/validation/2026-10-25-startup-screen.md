# 启动白屏与加载反馈

## 修改

- 主窗口创建时设置背景色，防止 WebView 在页面首次绘制前露出默认白底。
- 在 setup 阶段按主窗口配置创建窗口；Windows 在创建前关闭原生边框，Mac 保留原生窗口控件。
- HTML 自带内联启动样式和声波动画，主业务脚本/字体尚未下载或执行时也能显示。
- 独立启动脚本在绘制前读取已保存的深色、浅色或系统主题，以及界面语言。设置无法解析时使用与应用一致的深色默认值。
- React 首次提交直接替换启动内容，不增加固定等待或伪进度；超过 12 秒仍未挂载时提供重新加载入口。
- 字幕窗口从启动脚本开始即保持透明，不显示主窗口加载页。系统减少动态效果开启时关闭声波动画。

## 验证

- 前端构建和原生编译通过；Rust 测试 147 通过、23 项手动测试跳过。
- 脚本运行检查覆盖保存的主题、系统主题、无效/空设置、加载超时提示和字幕透明分支。
- 本地浏览器阻止主业务脚本加载的预览已人工检查，确认启动内容可独立呈现；预览图保存在忽略目录 `native/windows/.build/startup-preview.png`。
- Windows 安装包构建、安装后的文件比对及启动由本次本机更新验证；其他平台由分支 CI 继续检查。
