# 主动输入动画与工作台字幕配色

- 主动输入结果的原文、译文按词淡入，最长约 750 ms；动画仅影响视觉，不等待动画才播放语音。识别字幕沿用原有流式更新。
- 完整文本一次进入 DOM，可立即选择和复制；保留空格、标点和 Unicode 文本。最多每段 100 个动画节点，长文本不会产生大量逐字节点。
- 已显示的结果不因其他字幕更新、修改颜色而重新播放动画；系统减少动态效果时直接显示全文。
- 设置 → 常规 → 工作台字幕配色：语音识别和主动输入分别提供六种预设、任意自定义色和恢复默认。该分组控制工作台双语文本，悬浮字幕仍使用其已有的独立设置。
- 两组默认均为白色，并保留原文较弱、译文较强的层次；默认颜色跟随明暗主题保持可读性。
- 旧配置自动补齐默认值；只接受六位十六进制颜色，保存后重启保留，不影响服务选择或凭据。

验证：108 项前端测试、前端构建、格式检查、Mac `.app` 打包及签名校验通过。未修改 Rust 服务逻辑，未调用真实服务或改变用户密钥。

独立浏览器使用真实 React 界面验证：识别选黄色、主动输入选青色，保存并重新加载后选项保持；模拟识别和主动输入分别显示 `rgb(255, 224, 130)`、`rgb(128, 222, 234)`，主动输入节点具有 `expression-reveal` 动画及递增延迟，识别节点未改变。截图为模拟数据，保留在忽略目录 `native/macos/.build/caption-colors-ui.png`。

新版已打包，未重启用户正在使用的应用。
