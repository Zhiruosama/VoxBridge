# 卸载中断保留重试入口

问题：旧 `NSIS_HOOK_PREUNINSTALL` 在 Tauri 的应用运行检查之前删除维护快捷方式，后续检查中止时快捷方式已经丢失。排查时本机应用和卸载 EXE 仍存在，缺失的搜索/快捷入口不能直接等同于 EXE 被删除。

修复：

- 维护快捷方式只在 `POSTUNINSTALL` 成功路径清理。
- `PREUNINSTALL` 的第一步以独占写入/删除访问检查主程序文件，遇到运行中的映像或占用立即退出，错误码 2；不执行快捷方式、应用文件、注册表或用户数据清理。直接静默调用同样受保护。
- Rust 预检查将无法取得进程路径的同名进程按忙碌处理，不猜测为已退出。
- 界面先保持选项页并显示「正在检查」，原生预检查通过后才切换至卸载进度；失败返回选项页，可关闭或重试。

验证：`scripts/check-uninstall-safety.ps1` 编译真实 NSIS 检查宏，在独立夹具中验证已退出、文件锁定、运行中的模拟程序三种状态。忙碌两项都以错误码 2 退出，未跨越清理边界，应用、卸载 EXE、快捷入口和测试凭据均保留；正常退出项继续执行。未对用户应用发起实际卸载。

298 项前端测试通过，包含卸载前后钩子顺序契约；原生路径校验、格式与文档检查通过。普通及私下体验 Windows 安装包重建完成。本机以保留数据方式覆盖修复，应用、卸载 EXE、开始菜单应用和维护入口均恢复；设置记录逐字节一致，凭据文件相同。朋友体验包同步更新。
