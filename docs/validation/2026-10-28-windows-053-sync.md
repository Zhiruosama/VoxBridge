# Windows 0.5.3 同步与自动更新整合

同步基线：远端 main `cffc5e9`，包含 v0.5.3。工作分支保留上一轮尚未合并的自动更新功能，不修改已发布标签。

## 对照结果

- 本批上游没有新增 Mac 独占的 ASR、翻译、TTS 或音频路由业务。新增的 AppKit 标题栏、缩放动画及输入法面板仍限制在 macOS；Windows 保留 WebView2 原生焦点、自定义标题栏及最大化行为。
- 共享浮窗新增 `set_overlay_text_input` 命令，已注册并仅授权字幕浮窗；Windows 路径无需切换 AppKit 面板，正常返回，前端随后聚焦编辑器。
- 更新时的草稿暂存、重启恢复、具体阻塞原因及未保存密钥保护同步到 Windows。自动下载、倒计时安装、复用缓存包等路径统一在安装前暂存最新草稿；暂存失败不安装，安装失败清理暂存。
- 自动更新仍等待用户处理输入草稿；用户明确点击手动更新时可暂存并恢复草稿。开关、下载动画与配置独立保存保留。
- 新许可与第三方声明合并进入 Windows NSIS 资源，已核对生成的安装及卸载脚本包含两份文件。

## 验证

- 前端 291 项测试通过；新增自动安装暂存失败、缓存包重试、失败清理与自动/手动草稿策略测试。
- Windows Rust 171 项通过，25 项忽略；忽略项不计作通过。
- 前端构建、格式检查、文档链接及 5 项发布脚本测试通过。
- Windows 原生 `text-overlay-regression` 通过：合并配置可创建主窗、字幕窗及文本浮窗，独立原生句柄及最小尺寸正确；使用独立临时 WebView 配置，无用户设置、剪贴板或模型访问。示例退出时出现图标资源及 Chromium 窗口注销诊断，不影响通过断言与退出码 0。Mac 与 ARM64 实机行为不由此推断。

本批不发布新版本，不改变系统默认音频设备，也不调用付费语音服务。
