# 逐句与自然段字幕显示

[验证索引](README.md) · [使用方式](../guides/appearance.md#逐句与自然段) · [内部流程](../internal-flows.md)

## 本轮范围

基于用户新增的 StreamVox 显示调研，独立实现共享显示投影，不复制竞品代码或资源。未使用私有接口，也未发起收费识别、翻译或合成调用。

- 「常规 → 外观 → 字幕显示方式」提供逐句与自然段，默认逐句。主窗口、连续浮窗同步；紧凑浮窗仍显示最近三条。
- 已定稿的原文按顺序分组，每组最多三个短片段，并限制原文字符预算：CJK 片段采用 120 字符，其他片段采用 360 字符。这里是显示启发式，不是语义模型或真实停顿检测；混合语言按当前片段文字选择预算。
- 段落 ID、累计数量及字符数随会话成员保留，不因异步译文或历史头部裁剪重新分配。表达消息、未定稿尾部、会话与恢复代次之间分隔。
- 译文仍按成员 ID 回填；等待和失败保留对应位置。原文与译文分别连接，保留完整文字、逐成员阅读锚点和自动书写方向。
- 主窗口复用阅读跟随逻辑：回看、选择时暂停跟随，布局或译文更新时保持可见成员锚点。退出页面再返回时重新绑定观察。
- 不改变 ASR 与翻译适配器、请求正文、短句提交、并发上限及正常停止收尾。显示切换只更新设置与浮窗快照。

## 验证

- 前端回归覆盖三片段上限、CJK/拉丁预算、Unicode 计数、500 条历史裁剪后身份、乱序译文、待翻译与失败位置，以及会话/恢复代次/主动表达边界。
- 同一会话切换逐句和自然段时成员内容不变，主窗与浮窗使用相同段落身份。SSR 检查正文、提示和锚点不缺失。
- 中英、日文、泰文、韩文和阿拉伯文连接规则使用固定文本回放；缩写、小数与标点不被改写。
- Rust 快照拒绝未知显示方式和无效段落 ID，保留旧快照默认值及原有条数/字符上限。
- 使用共享组件的本地固定文本预览检查主窗与连续浮窗排版；未用用户音频或私人配置制作样本。

## 验证边界

自然段不用于推断真实停顿或识别说话人。完整 Windows 实机、持续长时间监听、触控板回看及晚到超长译文造成的实际滚动表现仍需体验确认；纯显示测试不能证明 ASR 准确度提高。短句质量策略、增量动画、VAD 与新供应商适配继续独立评估。
