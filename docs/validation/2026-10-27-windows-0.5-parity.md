# Windows 0.5 后端与浮窗对齐

[验证索引](README.md) · [Windows 待办](../windows-development-todo.md)

同步基线：远端主分支 `a5f444e`，版本 0.5.1。此次沿用共享业务实现，修复 Windows 平台装配缺口；不更换供应商、服务配置或系统默认音频设备。

## 对照结果

| 功能 | Windows 实现 |
| --- | --- |
| ASR 最终纠正、撤回与过期译文隔离 | 共用实时识别、分段修订及翻译任务代码，已随主分支同步 |
| 指定识别语言提示与 HTTP 短回答 | 共用模型能力检查、语言提示及 120 ms 有效声音门限 |
| 单声道电平、接近满幅与疑似抵消计量 | WASAPI PCM 进入同一个计量与诊断管线 |
| 剪贴板翻译 | 主窗口注册原生剪贴板插件及纯文字权限；监听和自动发送均默认关闭 |
| 文本翻译浮窗 | 补齐 Windows 独立窗口配置中遗漏的 `text-overlay`，恢复公共命令的实际窗口目标 |
| 浮窗内容、双语切换、独立外观和操作 | 共用快照、动作校验和窗口权限；Windows 使用系统拖动/缩放，Mac 使用 NSPanel |
| 虚拟麦克风测试与安装保护 | 测试音命令共用；Windows 包含最新默认设备快照和安装后条件恢复，不在启动时改默认设备 |
| 更新提示 | 共用每次启动一次的更新提示、签名验证及安装前忙碌保护 |

Mac 原生标题栏渐变、Spaces 和关闭后隐藏属于 AppKit 平台行为，不复制到 Windows。Windows 保留系统窗口约定、WASAPI 和当前用户 DPAPI。

## 防回归

- Tauri 的平台配置会替换整个窗口数组，而非按标签合并。新增自动检查要求 Windows 保留全部共享窗口标签，并保持浮窗路由、初始隐藏、不抢焦点、透明、置顶和最小尺寸一致。
- 既有译文目标语言校验测试从仅 Mac 执行改为两端执行，防止共享服务逻辑在 Windows 漏检。
- 原生窗口回归例程增加 Windows 分支：用实际合并配置创建三个独立隐藏 WebView，检查窗口身份、最小尺寸和隐藏状态。使用独立测试标识及空白页面，不读取用户剪贴板、配置或凭据，也不连接供应商。Windows GUI 示例补充 Common Controls v6 清单依赖；该链接选项只用于示例，不修改应用安装清单。
