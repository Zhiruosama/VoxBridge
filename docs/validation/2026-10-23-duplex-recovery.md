# 2026-10-23 同时收发与自动恢复

本轮完成用户优先指定的“边听边说”和自动恢复。这里的表达沿用文字输入 → 可选翻译 → TTS；真实麦克风翻译仍是后续功能。

## 同时收发

移除监听持有的音频输出许可，以及界面对文字翻译 / TTS 的监听互斥。指定进程采集与表达各自拥有任务和取消标识；停止监听不取消另一项文字表达，停止表达不取消监听。播放 / 测试音之间仍互斥，避免两个输出任务抢同一设备。

监听期间，文字表达翻译方向与字幕方向相反。例如字幕为英语 → 简体中文时，输入中文会翻译为英语输出；方向在输入框与输出模式按钮悬停提示中查看，不增加常驻小字。每次表达固定当时的方向及路由；监听结束不改变已在途的表达。没有监听时沿用原有方向，不改写保存的语言偏好。原文输出和已生成译文的直接播放不重复翻译。

本应用 PID 不可作为采集源，原生 tap 仍仅包含所选进程。此隔离不等于 Discord 的完整回环防护：聊天播放需使用耳机，发送需使用独立虚拟设备；未自动变更系统或聊天应用路由。

## 自动恢复

HTTP 分段与实时监听共用恢复监督器。连接超时 / 中断、服务暂时不可用、PCM 积压、采集丢帧 / 回调中断及部分 Core Audio 设备变化会清理本次采集、连接和翻译，再重建。无音频回调超过 5 秒或循环墙钟出现超过 5 秒的间隔会触发重新连接；正常静音帧不会触发。

- 连续重试间隔为 1、2、4、8、15、15 秒，最多 6 次；等待总和 45 秒，不包含连接和请求耗时。单轮持续 60 秒以上会恢复重试预算。
- 等待中可立即停止；达到上限后停止并提示，不无限重试。
- 认证、余额、额度 / 限流、权限、模型、协议和其他配置错误不盲目重试。权限不足需用户自行处理，应用不自动授权。
- 原 PID / bundle 仍存在时继续使用；否则只在非空 bundle 唯一匹配时恢复到新 PID。多候选、空 bundle 或身份改变时不猜测其他进程，不改为全系统采集。
- 新连接使用独立 generation、字幕 ID 和累计时间偏移。界面保留定稿、移除未定稿，拒绝旧代次迟到的进度、原文和译文。旧 PCM / 半句 / 在途翻译不重放；恢复间隙的声音不补录。
- 字幕翻译网络 / 临时服务错误独立最多重试两次，间隔 1、2 秒，可取消；仍失败时由监听恢复流程处理。字幕队列和过期边界仍保留。
- TTS 输出前若已保存的设备暂时不在线，最多等待同一稳定设备标识 20 秒，显示“等待设备…”，可停止，不切换默认设备。已开始播放的语音若中断会结束任务，不自动续播或重发，避免重复发送到聊天中。

系统凭据改在后台线程读取。早期实机并发测试暴露：同步 Keychain 查询会阻塞异步发送，导致实时 PCM 积压与开头丢失。修复后同一实机用例完整识别英文句子且未触发恢复。

## 验证结果

- 前端 70 项自动测试通过：并发时反向翻译、偏好不变、等待设备可取消、旧代次事件过滤、定稿保留等。
- Rust 67 项默认测试通过，15 项付费 / 硬件 / 辅助测试默认忽略。包括真实本地 WebSocket 断开后重新建连且仅发送新音频、有界退避 / 取消 / 预算恢复、安全源选择、输出设备等待，以及翻译 HTTP 503 后恢复成功。
- 严格 Clippy、格式检查、Mac `.app` 构建及 `codesign --verify --deep --strict` 通过。

手动实机测试只使用程序生成的声音 / 文字。付费调用使用已授权的 Keychain 凭据，不上传用户聊天或麦克风录音：

| 实机测试 | 结果 |
| --- | --- |
| Qwen 实时监听 + MiniMax 真实外置耳机输出，播放中停止 TTS | 监听继续；完整识别 “The meeting starts at ten tomorrow morning.”，完成对应中文翻译；修复后没有恢复事件 |
| 同一进程播放测试音、目标进程保持静音 | 目标采集 RMS = 0；目标自身发声正对照 RMS = 0.04 |
| 原生采集 + 本地模拟 ASR 断线 / 翻译 | 旧采集生命周期结束，重新创建采集与连接；新字幕 ID 和时间轴正确，定稿翻译完成；不调用付费服务 |
| 打包应用监听受控英文，同时输入中文点击翻译 | 英文 → 中文字幕和中文 → 英文表达各自完成，语音按钮保持可用 |
| 受控测试进程自动退出后的原生界面 | 显示“正在恢复”；达到重试上限后停止。再次测试恢复等待中手动停止监听，独立文字翻译仍完成 |

测试后未留下播放 / 采集任务，恢复测试前的语言设置并清理测试输入。

手动测试需明确授权，默认测试不会自行采集 / 播放或调用付费服务：

cargo test --manifest-path src-tauri/Cargo.toml --locked live_duplex_self_output_is_excluded_from_target -- --ignored --nocapture
cargo test --manifest-path src-tauri/Cargo.toml --locked live_native_capture_reconnects_and_releases_old_attempt -- --ignored --nocapture

## 实机边界

尚未实际拔插物理设备、执行整机睡眠唤醒、撤回 / 恢复系统权限或跑 30 分钟稳定性。回调中断和暂停检测已实现，不能据此宣称这些系统场景均已验收。输出设备重连等待已通过模拟测试，物理热插拔仍待测。

Chrome Discord 对端收发与真实回环仍待可用虚拟音频设备；当前没有可用虚拟输入 / 输出，未安装驱动、未加入通话或修改浏览器权限。此次耳机实测不能替代虚拟麦克风对端验收。
