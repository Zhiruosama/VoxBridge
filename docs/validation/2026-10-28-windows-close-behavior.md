# Windows 主窗口关闭行为

Windows 同步 Mac 已有的 `mainWindowCloseBehavior` 偏好，沿用 `hide` / `quit` 存储值，不改写旧配置。`hide` 在 Windows 映射为最小化到任务栏，在 Mac 仍隐藏窗口。

- 「设置 → 常规 → 外观 → 关闭主窗口时」在 Windows 提供「最小化到任务栏」与「退出应用」，保存后同步原生状态。
- Windows 主窗的 X、Alt+F4 等原生关闭请求走同一拦截：最小化模式取消关闭并最小化，保留主 WebView 与原生任务；退出模式沿用停止任务并退出的逻辑。不是隐藏到无入口的后台，不新增托盘。
- Mac 行为不变；字幕、文本浮窗、安装器不受主窗口最小化策略影响。

验证：前端 291 项测试通过，Rust 两项关闭行为测试通过（平台/窗口隔离以及退出设置），文档检查通过。本机安装与交互结果在完成构建后记录。长期后台任务运行与全平台实机回归不由单次窗口检查推断。
