# 文本翻译

[文档中心](../README.md) · [服务配置](services.md) · [排错指南](troubleshooting.md)

只想翻译文字时，使用左侧「文本翻译」。这里只需要文字翻译服务，不会调用 ASR、语音合成、录音或虚拟麦克风。

## 输入与翻译

1. 选择目标语言。原文语言默认自动识别，也可以手动指定。
2. 输入或粘贴文字，每次最多 2000 个字符。
3. 按 Enter 或点击「翻译」。Shift + Enter 换行；输入法确认候选词不会提交。
4. 在译文右上角点击复制，也可选择部分文字复制。

翻译期间仍可编辑文字。当前请求使用提交时的原文和目标语言，不会被后续编辑改变；同一时间不会重复提交另一条文本翻译。

## 等待、取消与重试

等待时显示耗时；超过 10 秒提示响应较慢。45 秒仍未完成会结束等待，保留内容并提供重试。

失败时先看译文区域的处理建议。点击「重试上一条」会重新提交失败时的原文和目标语言，使用当前翻译服务配置，不覆盖你正在编辑的新草稿。需要修改模型或密钥时，点击「翻译设置」。

可以随时取消。取消只结束当前请求，不删除输入或上一次成功的译文；迟到结果不会覆盖之后的新请求。重试由用户手动触发，不自动反复产生请求费用。

## 分栏与显示

- 拖动中间分隔条调整两栏比例，松开后自动记住；双击恢复等宽。
- 分隔条可用 Tab 聚焦，再用左右方向键微调。窄窗口自动上下排列。
- 「设置 → 常规 → 外观 → 文本翻译面板不透明度」控制背景、边缘和阴影，文字及按钮保持清晰。浅色面板与浅色底色接近时，透明度变化会比较细微。

切换到字幕页再回来，当前输入和译文仍在。它们只保留在本次运行期间，不保存为本地翻译历史；退出软件后清空。要长期保存请自行复制。
