# 开始使用

[文档中心](../README.md) · 下一步：[服务配置](services.md)

## 1. 安装软件

从 [Releases](https://github.com/Zhiruosama/VoxBridge/releases) 下载适合电脑的安装包。选择 DMG 或 EXE，其他签名、校验文件及 Source code 不是日常安装入口。

| 平台 | 安装包 | 支持范围 |
| --- | --- | --- |
| Mac | 文件名含 `aarch64.dmg` | Apple Silicon，macOS 14.2 或更高 |
| Windows | 文件名含 `x64-setup.exe` | Windows 11，Intel / AMD 电脑 |
| Windows ARM64 | 文件名含 `arm64-setup.exe` | 实验支持，实际音频硬件仍待验证 |

### Mac

打开 DMG，将 VoxBridge 拖入「应用程序」，然后从「应用程序」启动。更新时覆盖原应用即可。

应用尚未做 Developer ID 签名或公证。如果首次打开被系统拦截，先确认文件来自本仓库，再按 [Apple 的打开说明](https://support.apple.com/zh-cn/102445)在「隐私与安全性」中允许打开，不需要关闭系统整体安全保护。

### Windows

运行安装器，确认安装位置、快捷方式与是否安装虚拟麦克风。只做文本翻译或看字幕时，可以先不安装虚拟麦克风。缺少 WebView2 时，安装器会引导安装运行环境。

Windows 应用尚未做 Authenticode 签名；驱动安装需要系统管理员授权。详细步骤见 [Windows 安装指南](../windows-installation.md)。

## 2. 只配置你需要的服务

| 想用的功能 | 需要配置 |
| --- | --- |
| 翻译输入的文字 | 文字翻译 |
| 监听应用并看翻译字幕 | 语音识别 + 文字翻译 |
| 将打字内容翻译成语音 | 文字翻译 + 语音合成 |
| 录音后识别、翻译并发声 | 语音识别 + 文字翻译 + 语音合成 |

打开设置，进入对应服务页，选择预设或填写自己的接口地址与模型。保存 API Key，再保存配置更改。预设不附带密钥或额度；详见[服务配置](services.md)。

不需要给文字翻译授予录音权限，也不必先配置全部服务。

## 3. 试用一个功能

- **翻译文字**：左侧「文本翻译」→ 选择目标语言 → 输入文字 → Enter。Shift + Enter 换行。
- **看字幕**：左侧「字幕」→ 选择应用 → 让应用播放声音 → 开始监听。
- **生成语音**：在字幕页底部选择目标语言与音色，输入文字或录音后发送。先检查发送设备，避免发错位置。

要让聊天软件收到生成的声音，继续阅读[语音输入与虚拟麦克风](voice-output.md)。自己是否试听由耳机按钮单独控制。

## 4. 以后如何更新

启动时会检查更新，也可在「设置 → 常规 → 关于」手动检查。保存草稿和设置、结束音频任务后再安装更新。也可以从 Releases 下载新安装包覆盖安装，无需先卸载；同一用户、同一电脑上的配置与密钥会保留。

Windows 驱动的保留和卸载规则见[平台指南](../windows-installation.md#卸载应用与驱动)。应用更新签名用于验证下载包，不等于 Windows 或 Apple 的厂商签名。

遇到问题可先看[排错指南](troubleshooting.md)，无需重复卸载或重新填写所有密钥。
