# 监听与悬浮字幕

[文档中心](../README.md) · [服务配置](services.md) · [排错指南](troubleshooting.md)

## 开始监听应用

1. 配置语音识别与文字翻译服务。
2. 在左侧「字幕」页选择要监听的应用，例如 Chrome。
3. 让应用播放声音，点击「开始监听」，按系统提示允许相应音频访问。
4. 原文会随识别更新，译文稍后显示在对应条目中。

监听应用声音不等于录制实体麦克风。系统音频和麦克风可能有各自的授权提示；只在使用对应功能时处理该权限。

应用不在列表中时，重新展开应用选择器，或到「设置 → 常规 → 音频」刷新应用。浏览器的多个页面可能属于同一个应用采集范围，不能将“监听 Chrome”当作只监听某一个标签页。

## 修改字幕语言

在「设置 → 常规 → 监听字幕」修改识别语言和字幕语言。识别语言默认为自动识别。

字幕语言与底部发送语音的目标语言相互独立。改变界面语言也不会改写字幕或翻译目标。

## 使用悬浮字幕

点击「悬浮字幕」打开窗口，可拖动位置并在其他窗口上方阅读。Mac 浮窗支持其他桌面与全屏空间；多屏、睡眠唤醒和不同系统配置的表现仍需持续验证。

在设置中可选择连续或紧凑显示，以及原文、译文或双语内容，也可调整字号、行距、颜色和背景不透明度。

浮窗右下角提供麦克风和键盘入口。键盘输入框只在主动展开时出现，收起保留本次草稿；语音操作见[语音输入](voice-output.md)。

## 暂停与恢复

隐藏浮窗不会停止监听。要结束声音采集，请点击「停止监听」。监听停止时，实时路径会给尾句和待完成译文留出有限的收尾时间，不会无限等待。

网络或采集发生可恢复错误时，监听会进行有界恢复。应用退出、设备变化或权限失效时，先确认来源仍有效，再重新开始；手动停止后不会自行恢复。

单句翻译失败不会让整段监听停止。识别结果、断句和翻译质量仍受音源与模型影响，不保证多人通话能区分说话人。

## 阅读与外观

识别内容与主动输入内容可以使用不同颜色，在「常规 → 工作台字幕」调整。悬浮窗可跟随工作台配色，也可单独设置。

段落留白、字号、主题等统一见[外观与操作偏好](appearance.md)。
