# 服务配置

[文档中心](../README.md) · [开始使用](getting-started.md) · [排错指南](troubleshooting.md)

## 选哪一类服务

三类服务分别配置，可以来自不同厂商，也可以保存多个配置后切换。

| 设置页 | 用途 | 已接入的接口 |
| --- | --- | --- |
| 文字翻译 | 翻译输入文字和识别字幕 | OpenAI 兼容 Chat Completions，含 DeepSeek 预设 |
| 语音识别 | 监听应用声音、识别麦克风录音 | Qwen 实时 WebSocket、Qwen HTTP 短音频 |
| 语音合成 | 将文字生成声音 | MiniMax WebSocket、OpenAI 兼容 Speech |

预设只是填表帮助，不代表所有厂商、模型或语言都兼容。相同 API Key 也不意味着接口协议相同。开发者扩展服务时可参考[协议边界](../08-provider-configuration.md)。

## 保存一个配置

1. 打开对应设置页，在「新增配置」选择厂商预设，或新建空白配置。
2. 核对 API 地址、模型和接口类型。语音合成还需要选择音色。
3. 输入自己的 API Key，点击「保存密钥」。
4. 点击页面顶部「保存更改」。

配置和密钥是分别保存的。修改密钥后先保存，再测试服务；保存后重启无需重复输入或加载模板。空白配置不会自动切换到其他已有配置。

## 确认服务可用

- **文字翻译 → 测试连接**：发送一句短文本，检查当前服务、模型及已保存密钥能否完成翻译。
- **语音合成 → 测试连接**：生成一句短测试音频并清理，不播放，也不发送到虚拟麦克风。
- **语音识别 → 检查配置**：检查配置与密钥是否就绪。实际识别请进入「音频与诊断」，上传短音频验证。

翻译与合成测试会调用供应商，可能计费。使用私人克隆音色时，也按厂商对应音色规则计费。检查过程可以取消，修改配置会使之前的测试结果失效。

## 模型、音色和自定义预设

在模型或音色选择器中选择「手动输入…」，填入服务支持的标识并按 Enter 确认，Esc 取消。手动确认音色后会加入当前配置的音色预设；保存更改后重启保留。

「自定义预设」用于给常用模型和音色保存易认的名称，每类最多 50 条，按服务配置和协议区分。删除单条预设不会删除服务或密钥；删除整个服务配置会同时删除其密钥。

私人克隆音色通常与供应商账号绑定。切换账号后，应确认新账号是否有该音色的使用权限，不能仅复制音色标识就保证可用。

## 翻译风格与语言

「文字翻译 → 翻译风格」控制措辞，默认偏向自然、简洁的日常聊天表达。它不替代目标语言设置，留空时使用默认风格。

监听识别语言默认为自动识别；字幕语言在「常规 → 监听字幕」中修改。输入框旁的语言控制生成语音的目标语言；独立文本翻译页有自己的语言选择。

当前界面提供中文、英语、日语、韩语、西班牙语、印尼语、粤语、芬兰语、俄语和德语。实际识别、发音及音色表现仍取决于所选服务与模型。同语言输入在能够确认时可直接合成；混合语言、不确定输入和书面粤语可能仍走翻译流程。

## 语速、情绪与声音效果

输入框底部的音色菜单可切换已配置的语音服务、模型、音色与语速。监听期间也能切换，之后提交的新任务使用新配置，已排队或正在播放的任务保持原配置。

MiniMax 协议下会显示情绪、音量、音调及高级声音设置；其他兼容接口不会收到这些专属参数。情绪选项随模型能力变化，不支持的选项不会强行发送。

- 音量默认 1，音调默认 0；不确定时先保留默认值。
- 高级声音设置可调音色修饰、音效和发音替换。效果是否自然，需要用自己的音色实际试听。
- 发音替换每行使用 `原词/读法`，例如 `VoxBridge/vox bridge`，最多 50 行。
- 某些模型支持停顿或情绪文本标签；翻译过程不保证保留这些标记，不建议把标签当作通用语法。

「服务扩展参数」中的思考模式只应在供应商明确支持时设置。不确定时选择「服务默认」，避免兼容接口因额外参数而报错。

## 数据与费用

文字或音频会发送给你配置的模型供应商，按其规则计费。VoxBridge 不提供云服务额度，也不会把私人音色打包给其他人。

密钥保存在本机私有存储中，不写入普通设置文件、翻译历史或诊断正文。不要在反馈问题时上传 API Key、录音或完整私人配置；日志导出见[诊断说明](../diagnostics.md)。
