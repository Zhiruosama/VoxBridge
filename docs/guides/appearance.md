# 外观与操作偏好

[文档中心](../README.md) · [文本翻译](text-translation.md) · [监听与悬浮字幕](listening.md)

修改设置后点击「保存更改」，下次启动会保留。自定义预设名称、草稿和翻译内容不会随界面语言切换而改变。

## 主窗口

| 设置或操作 | 作用 |
| --- | --- |
| 常规 → 外观 → 界面语言 | 简体中文或 English，主窗口与悬浮窗同步 |
| 常规 → 外观 → 主题 | 浅色、深色或跟随系统 |
| 拖动侧栏边界 | 调整侧栏宽度；双击恢复默认，也可用方向键微调 |
| 常规 → 外观 → 字幕显示方式 | 逐句或自然段；主窗口与连续悬浮窗同步，切换立即预览 |
| 常规 → 外观 → 字幕段落间距 | 调整主窗口相邻字幕的留白 |
| 常规 → 工作台字幕 | 调整字号，以及语音识别、主动输入两类内容的颜色 |

字号和段落间距属于字幕设置，不会统一改变所有按钮或设置页文字。

侧栏宽度会根据窗口大小设限，到达边界后不能继续向右拖宽；主窗口也有最小宽度，避免把底部输入工具栏挤成两行。拉宽窗口后可继续扩大侧栏，双击侧栏边界恢复默认宽度。

## 逐句与自然段

逐句保留每条字幕的独立显示；自然段把相邻、已经定稿的识别短句组织成较连贯的段落。译文仍随每个短句到达，不等待整段说完，也不会因为切换显示方式重新识别或翻译。

自然段按短句数量和原文长度限制大小。临时识别尾部、重连后的新音频和主动输入消息保持分隔；这不是说话人识别功能。翻译尚未完成或失败时，保留原文与对应提示，其他译文可以正常显示。

连续悬浮窗跟随此设置，紧凑悬浮窗仍逐条显示最近字幕。回看或选择字幕时暂停自动跟随，点击「最新」返回底部。

## 文本翻译面板

中间分隔条可调整左右比例，自动保存；双击恢复等宽。窄窗口会自动改为上下排列。

「常规 → 外观 → 文本翻译面板不透明度」只调整背景、边缘和阴影，原文、译文及按钮不会跟着变淡。设为 0% 时卡片表面消失，文字仍显示；浅色底色相近时，细微变化可能不明显。此设置不让整个软件窗口穿透到桌面。

## 悬浮字幕

在「常规 → 悬浮字幕」中调整显示模式、双语字幕、字号、行距及背景不透明度。开启“双语字幕”显示原文和译文，关闭后仅显示译文。悬浮窗顶部也有同样的开关，切换后立即保存并同步到设置，重启后保留；不会改变主窗口字幕或重新请求识别、翻译。

配色来源可选择跟随工作台，或为悬浮字幕单独设置。键盘输入框只有手动打开时出现，收起不会立即删除草稿。

## 输入与窗口操作

- 文本翻译页：Enter 翻译，Shift + Enter 换行。
- 字幕页输入框：Enter 按「常规 → 文字表达」中的偏好操作。
- Mac 红色关闭按钮默认隐藏主窗口，监听和语音任务继续；点击 Dock 图标重新打开。可在「常规 → 外观 → 关闭主窗口时」选择退出应用，保存后生效。真正退出使用 ⌘Q 或应用菜单「退出 VoxBridge」。
- Mac 黄色按钮仍用于最小化。Windows 可在「常规 → 外观 → 关闭主窗口时」选择「最小化到任务栏」或「退出应用」，保存后生效。默认最小化，点击任务栏图标恢复窗口；选择退出会结束任务并关闭软件。字幕和文本浮窗的关闭按钮仍只收起浮窗。
- 隐藏悬浮窗不会停止监听，结束采集请点击「停止监听」。

悬浮窗四边可以单独调整宽高，四角可以同时调整；鼠标靠近边缘或四角会显示缩放指针，不需要精确对准边框细线。顶部空白区域仍用于移动窗口。


Mac 原生标题栏与页面背景使用同一动画进度柔和过渡，文字保持清晰，快速来回切换会从当前颜色继续；首次启动和系统开启「减少动态效果」时直接应用主题。保留原生红黄绿按钮，不改变 Windows 窗口布局。
