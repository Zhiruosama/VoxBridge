# 语音输入与虚拟麦克风

[文档中心](../README.md) · [服务配置](services.md) · [排错指南](troubleshooting.md)

发送语音的流程是：输入文字或录音 → 可选翻译 → 语音合成 → 指定输出设备。麦克风录音经过识别和重新合成，不直接转发原始录音。

## 先确认声音发到哪里

**发送设备决定对方收到什么，试听设备决定自己听到什么。** 要让聊天软件收到语音，需要虚拟麦克风；只在本机听声音可以使用试听。

| 平台 | VoxBridge 的发送设备 | 聊天软件的输入设备 |
| --- | --- | --- |
| Mac | VoxBridge | VoxBridge |
| Windows | CABLE Input (VB-Audio Virtual Cable) | CABLE Output (VB-Audio Virtual Cable) |

试听设备选择系统默认或自己的耳机。不要把虚拟设备设为日常系统默认扬声器，以免其他应用的声音也进入通话。

新用户的发送设备默认是「自动选择虚拟麦克风（推荐）」。驱动的两端未完整就绪时，发送会提示安装/重启，不会把本应进入通话的声音退回扬声器。已有用户保存的扬声器、系统默认或其他设备不会被自动改写；如需修改，请到「设置 → 常规 → 音频」选择发送设备并保存。聊天软件仍须明确选择上表中的输入设备，应用不会更改 Windows 的默认麦克风。

### 安装虚拟麦克风

先结束通话，再安装驱动：

- **Mac**：设置 → 常规 → 音频 → 虚拟麦克风，按提示安装 VoxBridge 驱动。
- **Windows**：在应用安装流程或设置页安装基础版 VB-CABLE，并按厂商提示重启电脑。详细步骤见 [Windows 安装指南](../windows-installation.md)。

驱动安装由系统申请管理员授权。Windows 使用 VB-Audio 的驱动，保留其厂商来源；修改端点显示名不会把它变成 VoxBridge 自有驱动。

## 打字后发送

在字幕页底部选择输出语言与音色，输入文字后点击发送。Enter 默认输出语音，可在「常规 → 文字表达 → Enter 操作」修改；Shift + Enter 换行。

- 「翻译」按钮只翻译，双语内容显示在上方字幕区。
- 「原文 / 译文」决定合成哪份文字；原文输出不需要先翻译。
- 耳机按钮控制自己是否试听，不影响发送设备。
- 发送后输入框清空，可以继续编辑并提交下一条。

第一次测试可先选择「原文」并配置语音合成，排除尚未填写的文字翻译服务。发送译文通常还需要完整的文字翻译配置。仅在使用对应功能时检查所需服务配置与输出设备，未通过时提示错误及配置入口，保留输入且不入队。工作台不常驻显示配置或路由提示；本机检查也不能证明 API Key、余额或云服务已经正常。

只需要文字结果时，使用[独立文本翻译](text-translation.md)会更直接。

## 根据聊天上下文调整语气

在「设置 → 常规 → 文字表达」开启「上下文语气」。使用 MiniMax 并发送译文语音时，当前文字翻译服务会在同一次请求中返回译文与建议的情绪、语速；主窗口和字幕悬浮窗共用此设置。默认关闭，便于对照试听。

上下文包括最近一分钟内监听到的已确认字幕，以及自己已经开始播放发送的内容，最多 12 条、4000 字符。只保存在内存中，重新开始监听或退出软件会清空；不监听时仍可参考自己的近期发言。软件不会读取 Discord 文字聊天，也不能区分混合音频中每个说话者的身份。

开启后，这些近期内容会随请求发送给当前文字翻译服务。没有历史也能使用，不需要手动填写背景。同语言输入保留内容，但仍请求语气判断；纯文本翻译和原文直出不受影响。

自动语速只在你设置的基础上调整最多 ±10%，音色、音高、音量和音效保持原设置。手动指定情绪时优先使用整套手动语音设置。模型返回无效语气字段时使用默认语气；不支持 JSON 或返回无效结构时最多退回一次普通翻译。认证、余额、网络或普通翻译本身失败时仍按原来的错误流程处理。

语气建议不能恢复原始声音中的情绪，也不保证解决克隆音色的机械感。可使用相同音色与句子，切换此开关比较效果。

## 录音后发送

点击麦克风开始录音，再点击结束，最长 1 分钟，期间可以取消。

默认将识别结果填入输入框，确认或修改后再发送。开启「直接发送」后，结束录音会自动识别、翻译并合成；录音期间改过草稿时，会先等待确认以避免误发。

「设置 → 常规 → 音频 → 语音输入麦克风」用于选择实体麦克风，默认跟随系统输入。悬浮窗的麦克风和键盘入口也可使用，和主窗口共用任务与队列。

## 队列、停止与试听

「队列」入口只显示简洁名称，点开后查看处理阶段、数量和目标语言。最多保留 10 条，翻译和语音准备可并行，声音按顺序串行输出。

- 可暂停、继续、编辑、重试或取消单项。
- 停止当前输出会暂停后续队列，需要时再点「继续」。
- 失败项保留内容，不阻塞后续条目。重试或编辑失败项会排到队尾，可能重新计费。
- 已排队任务使用提交时的配置，之后切换音色或语言只影响新任务。
- 队列只保留在本次运行期间，退出会取消任务。

发送与试听使用同一份合成结果。播放中切换试听不重新合成，中途开启只播放后续部分。「系统默认」试听设备会在开始播放时读取当前系统输出，适合经常连接或拔出耳机的情况。

## 在 Discord 中检查

1. 在 Discord 语音设置里选择上表的输入设备，输出仍使用耳机或扬声器。网页端还需允许相应麦克风访问。
2. 打开 Discord 的麦克风测试，关闭 VoxBridge 自身试听，避免两路回放叠加。
3. 在 VoxBridge 发送一句短语，确认 Discord 能收到。
4. 声音断续时，可尝试「工作室」输入配置，排除降噪或回声抵消影响。结束测试后关闭麦克风调试。

Mac 主要在 Discord 中验证。Windows 已有本机虚拟音频回环验证，但不能据此保证所有客户端通话兼容。QQ、微信及其他聊天软件的限制见[排错指南](troubleshooting.md#聊天软件看不到虚拟麦克风)。
