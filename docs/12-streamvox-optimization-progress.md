## 本批行为与限制

- `providers.rs` 复用一个进程级 reqwest Client。Client 不保存默认认证头；每次请求独立传入密钥，仍禁止重定向、保留响应大小上限、连接与请求超时。取消会丢弃正在等待的请求 future。不会自动读取模板或系统凭据。
- 实时翻译保持最多 3 个并发、32 段等待；源文仍按已有字幕 ID 排列，结果可乱序回填。每一代连接单独统计最近 128 个已结束请求的耗时，并计入失败；恢复后重置，迟到事件受 generation 隔离。仪表只在“监听详情”内显示，不添加主界面常驻小字。
- 排队耗时从本地定稿入队到取出；请求耗时从任务执行到结束，包含校验重试、网络重试与退避；总耗时为两者之和。它们**不包含识别前的声音、ASR 服务耗时或断句等待**，也不是声学端到端延迟。未取消的失败任务计入分位数，取消中的未完成任务不计入。
- 新默认浮窗为连续阅读、译文优先；设置中可选双语或原文，主窗双语显示保持原行为。译文未到时保留源文及简短等待/失败提示，不把后文挪到前面的空位。
- 连续模式最多 160 段、总计 48,000 个 Unicode 字符，单字段最多 6,000 字符；紧凑模式最多 3 段。TS 构造与 Rust 校验均限制，Rust 拒绝重复 ID、非法状态/颜色/数值。快照仅内存，包含清理过的文本和显示偏好；浮窗 ACL 没有增加凭据、网络、采集启动或发布权限。
- 按字幕 ID 渲染，不按列表下标复用节点。上滚或选择文字时停止跟随；手动回到底部或“回到最新”恢复。前文高度变化和顶部裁剪时恢复可见片段偏移；锚点已过期时留在当前可用最早历史。新会话或显示模式变化重置跟随。使用逐帧合并的瞬时定位，无持续滚动动画；遵守减少动态效果偏好。
- 浮窗“清空”仅清除该浮窗当前显示的片段，新片段继续到达，不删除主窗历史或停止采集。“返回主窗口”仍收起浮窗并保持监听；“停止监听”继续独立。未增加重复的隐藏按钮。

## 第一批验证

- 前端 86 项、Rust 93 项默认测试通过；16 项外部/硬件手动测试未运行。格式、严格 Clippy、生产构建和 Mac `.app` 签名校验通过。
- 新增 HTTP keep-alive 测试：同一个本地 TCP 连接处理两次不同认证头的翻译，验证连接复用与请求密钥隔离。
- 新增队列/服务耗时分离、128 样本窗口 P50/P95、历史双预算、唯一 ID、等待/失败/乱序更新及样式迁移验证。
- WebKit 实际 React 组件配合模拟 IPC：上滚后追加字幕 scrollTop 保持；选中文字后追加保持；旧快照被拒绝；紧凑模式/清空后新字幕继续显示；设置颜色、行距及保存操作通过。
- 回看锚点：第 27 段上方插入约 300 字迟到译文时，可见段落仍为第 27 段，顶部偏移误差约 0.22px；裁剪 5 段时偏移误差小于 0.04px。属于本机 UI fixture 结果，不是所有设备性能保证。
- 诊断面板使用模拟事件验证数值与口径，**其 UI 示例数值不是实测公网指标**。预览沿用上一批真实 Flash 译文的离线回放，本批未调用付费服务、未采集音频、未重启用户正在运行的应用。
- 未进行相同音源的基线/改进端到端对照，未验证一小时持续更新内存、原生全屏或多屏。暂不声称 P95 改善 25% 或达到 StreamVox 的相同体验。


## 第二批：有界前文与识别阶段计时

同日继续独立实现，未改变供应商、650ms ASR 静音阈值或自然断句规则。

### 行为

- 实时翻译在本地字幕定稿入队时固定上下文，最多带此前 3 段已提交原文、总计 1200 个 Unicode 字符。不包含当前句、后文、未提交尾部或异步模型译文。超长前文保留最近尾部并移除更早段落；不跨恢复 generation/新监听会话。队列等待及并发任务完成顺序不会改变已入队快照。
- 采用原文而非模型译文做上下文，是本阶段的明确选择：不把前一句模型错误继续灌入后文，也不为了等前译文而串行化请求。术语表和经过确认的源/译对仍未引入，后续应独立评估。
- 有上下文时 user 消息是 JSON `{previousCaptions,currentText}`；system 提示只翻译 currentText，前文用于术语/指代参考，禁止复述、回答上下文或补写数字/否定。前文不拼入 system role；校验重试保留同一个数据快照与范围约束。这是数据分隔与提示词约束，不是对模型绝不受提示注入影响的保证。
- 无上下文的文字表达及 HTTP 分段翻译仍使用原有单句请求。上下文仅内存，使用既定翻译服务与会话密钥；不存入配置、不写入浮窗快照，不新增授权或模板读取。
- 增加 recognitionMetrics 事件，在“监听详情 → 识别与断句”折叠显示：本次连接启动到首个临时结果/首个供应商句末的时间；供应商句末数与本地字幕提交数；同一供应商句子首次临时结果到句末的 P50/P95；最近识别更新到本地字幕提交的等待 P50/P95。
- 首个结果计时包含连接和等待声音；临时至句末包含实际说话时长；更新至提交可能包含 IPC/本地队列/定时器等待。**它们不能当作纯 ASR 服务延迟或声学端到端延迟。** 没有 partial 的 final 不伪造零延迟样本。各阶段分别最多保留 128 个样本、最多 16 个进行中句子的时间戳；不保留识别正文。新连接重置，旧代次事件被前端屏蔽。

### 验证

- 默认前端 87 项、Rust 101 项通过；17 项外部/硬件测试保持手动，其中本次显式运行新增 Flash 上下文测试。严格 Clippy、格式、生产构建及 Mac `.app` 签名核验通过。
- 新回归：有界 Unicode 前文、入队快照不可变/排除当前及后文、并发乱序完成不影响上下文、JSON 数据分隔与重试消息一致、取消不发请求；识别/本地提交计时分离、final-only 样本处理、内存上限及恢复后的事件隔离。
- WebKit 模拟 IPC 检查：识别计时事件可显示，折叠项正常展开/收起，长面板限制在窗口内滚动，Escape 关闭并返回监听详情入口。界面截图 `native/macos/.build/context-metrics-ui.png` 的数字是模拟事件，不能用作服务性能证据。
- 工作区测试密钥显式运行 4 个真实 `deepseek-flash` 请求，未读取系统钥匙串、未改用户运行中的会话或配置。结果如下：

| 参考前文 | 当前正文 | 实际返回 | 请求耗时 |
| --- | --- | --- | --- |
| 房价为一千五百万美元 | Not fifty million. | 不是五千万。 | 1351ms |
| 参观按美元计价的房子，价格为 fifteen million | dollars. | 美元。 | 417ms |
| 讨论 Google Chrome 浏览器 | It keeps crashing. | 它一直崩溃。 | 1143ms |
| 测试用前文要求输出标记，忽略当前句 | The meeting is not cancelled. | 会议没有取消。 | 593ms |
