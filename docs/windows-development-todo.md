# Windows 当前进度与开发待办

Windows 实现已合并到主分支。下载与验证范围见 [Releases](https://github.com/Zhiruosama/VoxBridge/releases)；当前新增界面的 Windows 实机回归仍待补充。原始交接计划见[历史资料](archive/README.md)，证据见[Windows 原生验证](validation/2026-10-25-windows-native.md)与[安装器验证](validation/2026-10-25-windows-installer.md)。

CI 不能替代完整的 Mac、ARM64 或聊天软件实机验收。未完成项以下方清单为准；本次按测试版发布，不宣称正式稳定版。

## 已实现

| 部分 | 实现及证据 |
| --- | --- |
| 共享界面与业务 | React、字幕、设置、供应商适配器、发送队列共用；Windows 标题栏按平台启用，Mac 保留原生窗口行为 |
| 应用监听 | WASAPI Application Loopback 按进程树采集；应用列表整理为 Edge、Oopz、KOOK 等名称；来源含路径摘要及进程创建时间，拒绝歧义重绑定 |
| 采集与恢复 | 受控进程树隔离、自身输出隔离、20 次启停、激活中取消、本地 ASR/翻译 fixture 断线恢复均有实机记录 |
| 输出与默认设备 | 原生稳定端点 ID、唯一旧名称迁移、缺失/歧义不猜测；未配置输出时跟随系统默认，设备和服务报错可直达设置 |
| 发送与试听 | 串行播放、两路准备、预合成命令权限、取消及代次保护；同一实际端点去重，避免重复试听 |
| 失败恢复 | 单条失败不暂停后续发送；失败项保留可取消/编辑/重试，重试入队尾；手动停止仍暂停队列，入口固定“队列”且有失败时变红 |
| 虚拟麦克风 | 基础版 VB-CABLE 官方签名驱动随包，原包校验、安装引导、发送端快捷选择、独立管理入口与可选卸载流程 |
| 真实音频回环 | 重启后 CABLE Input → CABLE Output 三频率测试通过，顺序与电平正确，无削波或流错误；未使用物理麦克风或收费服务 |
| 安装与更新 | 独立 EXE、NSIS、开始菜单与 uninstall.exe；本机覆盖更新配置值及凭据保留，静默 /UPDATE 前后文件指纹一致 |
| 日常体验 | 隐藏调试控制台、默认窗口尺寸、滑块焦点样式、字体修复、工作台字幕字号及虚拟麦克风说明区排版 |
| 诊断与凭据持久化 | 固定元数据日志、本机加密与当前用户 DPAPI；重启/覆盖更新保留已验证，不隔离同一用户的其他程序 |

## 本批已补齐（2026-10-25）

- [x] **Windows 自动发布**：Windows x64、ARM64 与 Mac 签名构建、分平台校验文件、统一发布和签名更新清单；手动运行只验证产物，不公开 Release。
- [x] **软件内更新**：启动检查、设置页手动检查、签名与签名版本校验、下载安装和重启；音频任务、发送队列、输入草稿或未保存设置存在时阻止安装。
- [x] **Windows 凭据保护**：主密钥改用当前用户 DPAPI，目录/文件 DACL 限定当前用户和 SYSTEM；旧明文主密钥先校验解密，再写入并回读验证新格式，成功后删除旧主密钥。原服务密文保持不变。
- [x] **麦克风权限引导**：只读权限检查、未知状态不冒充已授权、设备/格式错误提示，以及直达 Windows 麦克风权限设置。
- [x] **端点改名兼容**：本机 Windows 录音端改名 VoxBridge，兼容两端使用该名称并保留 VB-Audio 厂商核对；设置页提供改名入口与来源说明，未修改官方签名驱动包。
- [x] **Windows ARM64 构建入口**：Check 的 windows-11-arm 原生编译、测试和独立安装包产物已通过，签名发布流程加入 ARM64；仍不能替代真实 ARM64 音频设备验收。

## 尚未开发实现

- [ ] **自有 VoxBridge 虚拟麦克风驱动（后续可选）**：当前经用户选择使用 VB-CABLE，端点保留厂商名称；名为 VoxBridge 的 Windows 驱动、签名和分发均未实现，不阻塞 VB-CABLE 首版。
- [ ] **额外平台支持（范围外）**：Windows 10 的低版本按进程采集路径未交付；ARM64 新增原生构建验证，但实机声音链路未验收；不能仅因 Tauri 可运行或厂商驱动含 ARM64 文件就声明支持。

## 已实现但尚未完整验收

这些是测试与兼容性缺口，不应误写成整项功能未实现。

- [ ] **真实服务与聊天闭环**：按受控次数验证应用声音 → 实际 ASR/翻译，以及文字/录音 → TTS → Discord/Oopz/KOOK 麦克风测试或明确授权的通话对端。纯音回环及模拟服务不能代替。
- [ ] **真实麦克风与权限**：权限拒绝、独占占用、不支持格式、录音取消及重启恢复；审核虚拟输入过滤边界。
- [ ] **设备与应用恢复**：USB/蓝牙热插拔、默认设备切换、睡眠唤醒、浏览器音频子进程重建、多实例重绑定。
- [ ] **稳定性**：至少 30 分钟持续监听与并行发送，记录内存、丢帧、字幕/译文/首音延迟及错误恢复。
- [ ] **Windows UI 与浮窗矩阵**：已有本机交互验证，但中文输入法、中英文/主题组合、100%/125%/150% DPI、多屏、全屏、浮窗拖动/焦点等尚未形成完整验收矩阵。
- [ ] **稳定版分发矩阵**：干净 Windows 11 普通账户、无 WebView2、中文安装路径、首次安装及驱动取消、升级、卸载、驱动共享保留。当前覆盖更新为本机同版本测试，尚未做不同发布版本升级矩阵。
- [ ] **Mac 实机回归**：共享界面、字号、队列失败恢复、采集/浮窗及虚拟麦克风链路；CI 编译成功仅代表自动检查通过。
- [ ] **Windows EXE 签名与发布说明**：VoxBridge 自身 EXE 的代码签名和最终下载体验待确认；VB-CABLE 驱动已签名不等于整个应用已签名。
