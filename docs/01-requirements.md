## 1. 目标与约束

VoxBridge 帮助用户理解其他应用的语音，并通过合成语音参与跨语言交流。首版面向单用户桌面使用，不要求向 Discord 或直播平台安装插件。

已确认约束：

- 长期支持 macOS / Windows，当前优先 macOS。
- 本轮交付 README 与设计文档供 review，不开展业务实现。
- 当前开发机为 Windows，2026-10-23 计划转到 Mac 适配；不在 Windows 上宣称原生音频已验证。
- 需要识别系统声音、翻译、双语展示、透明悬浮窗，以及向虚拟麦克风输出合成语音。
- 重视低延迟与可控成本；具体阈值尚未由用户确认。

## 2. 主要场景

### 场景 A：看直播 / 听语音聊天

用户选择目标应用、源语言和目标语言，开始监听。界面先显示识别中的原文，再显示稳定译文；悬浮窗在其他应用上方展示双语。暂停后不再采集，不再产生新服务请求。

### 场景 B：通过文字参与语音聊天

用户选择输出语言与音色，输入文字，可选翻译。试听只向耳机播放；发送才向虚拟设备播放。用户在 Discord 中选择该虚拟录音设备作为输入。点击停止后中止当前发送并清空待播队列。

### 场景 C：用真实麦克风进行翻译表达

用户使用按住说话或显式开始 / 结束，系统将语音转成文字、翻译后合成并发送。该能力安排在 A/B 稳定后；初期建议采用按住说话，降低误触发和分句不确定性。

## 3. 功能分级

| 编号 | 优先级 | 需求 | 验收要点 |
| --- | --- | --- | --- |
| F01 | 原型必需 | 枚举并选择采集应用、输出设备 | 可区分同名设备；进程退出有提示 |
| F02 | 原型必需 | 系统音频采集与电平显示 | 正常播放可检测；静音不虚构字幕 |
| F03 | 原型必需 | 流式 ASR 与短句翻译 | 中间结果可更新；定稿不重复提交 |
| F04 | 原型必需 | 主窗口双语字幕 | 原文译文按句对应，断线状态明确 |
| F05 | 原型必需 | 文字 TTS、试听、虚拟设备发送、停止 | 试听不发送；停止后不续播旧内容 |
| F06 | 首版必需 | 悬浮窗 | 置顶、拖动、字号、透明度；穿透可恢复 |
| F07 | 首版必需 | API 与语言设置 | 凭据安全保存；失败后可修改重试 |
| F08 | 首版必需 | 权限与设备恢复 | 拒绝权限、设备断开后可恢复 |
| F09 | 后续增量 | 真实麦克风识别翻译输出 | 与接收链路互不串音 |
| F10 | 后续增量 | 本地 ASR | 与同一录音的云端基准比较再决策 |

## 4. 默认范围与非目标

建议先验收普通话与英语双向；其他语言由具体服务支持范围及实测决定。暂不承诺粤语、混合语言、多人重叠发言的准确度。

第一版不做说话人分离、声纹克隆、系统默认麦克风自动切换、自动回复、长时录音存档、自研虚拟音频驱动或自建商业计费后台。用户可以在聊天软件中手动选择虚拟输入；VoxBridge 不暗中更改系统默认设备。

## 5. 成功与验收

以下是待确认的工程目标，不是性能承诺：

| 项目 | 初始目标 | 测量方式 |
| --- | --- | --- |
| 初始原文 | 从语音开始到首个非空识别结果 p95 ≤ 1.5 秒 | 固定录音回放，记录时间戳 |
| 翻译等待 | 从短句定稿到完整译文 p95 ≤ 1.5 秒 | 记录 ASR 定稿与译文完成事件 |
| 文字发送首音 | 从点击发送到虚拟输出首帧 p95 ≤ 2 秒 | 单独统计无需翻译 / 需要翻译两组 |
| 停止响应 | 点击停止到本地不再提交播放帧 ≤ 300 毫秒 | 测本地输出；不含对端网络缓冲 |
| 连续运行 | 单次 30 分钟，不崩溃、不持续堆积队列 | 记录内存、队列年龄、掉帧与错误 |
| 路由正确性 | 试听不进入虚拟麦克风，发送不被自身 ASR 再采集 | Mac 上录音 / 对端回听 |

性能测试记录机型、系统、网络、服务区域、模型、语料与至少 30 个有效样本。30 分钟为稳定性冒烟标准，不等于长时间可靠性已证明。

质量先采用固定中英语料和真实聊天片段人工评审，记录漏句、重复、专有名词、否定和数字错误。先建立基线，再制定识别与翻译质量阈值；不能仅凭延迟通过判定可用。
