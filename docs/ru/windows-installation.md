# Установка, обновление и удаление в Windows

[Документация](README.md) · [Начало работы](guides/getting-started.md) · [Вывод речи](guides/voice-output.md)

## Установка приложения

1. Скачайте установщик Windows из [Releases](https://github.com/Zhiruosama/VoxBridge/releases). Для обычного компьютера Intel / AMD нужен `x64-setup.exe`, для ARM — `arm64-setup.exe`.
2. Откройте установщик, выберите папку и ярлыки. Если WebView2 отсутствует, установщик предложит установить среду выполнения.
3. Для перевода текста и субтитров виртуальный микрофон можно пропустить. Установите драйвер, когда понадобится передавать синтезированную речь в приложение общения.
4. Запустите приложение и сохраните свои сервисы и ключи по [инструкции](guides/services.md).

В установщике и программе удаления можно выбрать «Русский». В самом приложении язык выбирается отдельно в основных настройках оформления.

## Установка и выбор виртуального микрофона

Установщик содержит полный неизменённый официальный пакет базового VB-CABLE. Проверяются SHA-256 и цифровая подпись программы установки драйвера.

1. Отметьте виртуальный микрофон при установке либо позже откройте менеджер в «Настройки → Основные → Виртуальный микрофон → Установить или удалить драйвер».
2. Разрешите операцию администратора в Windows и нажмите **Install Driver** в официальном менеджере VB-Audio.
3. Перезагрузите компьютер по инструкции, затем откройте VoxBridge и приложение общения.
4. Выберите устройства из таблицы, сохраните настройки и проверьте звук тестом микрофона в приложении общения.

| Где | Устройство |
| --- | --- |
| Отправка в VoxBridge | **CABLE Input** |
| Микрофон Discord, KOOK и других приложений | **CABLE Output** |
| Прослушивание в VoxBridge | **Системное устройство** или реальные наушники / динамики |

В настройках звука Windows можно переименовать соответствующие устройства в **VoxBridge**, затем выбирать новое имя. Маршрутизация использует стабильные ID; переименование не делает VB-CABLE собственным драйвером проекта. Системный микрофон по умолчанию менять не нужно.

Перед установкой менеджер запоминает системные устройства ввода, вывода и связи. Он восстанавливает их только если установщик поставщика заменил их на VB-CABLE. После первой установки при следующем входе выполняется ещё одна проверка, затем задача восстановления удаляется. Если прежнее устройство отключено или пользователь выбрал другое физическое устройство, принудительного возврата нет. При ошибке восстановления появится предложение проверить настройки звука вручную.

**Завершение установки ещё не означает передачу звука.** Новая конфигурация автоматически выбирает виртуальный микрофон для отправки, но существующие настройки не перезаписываются. Если ранее были выбраны динамики, в «Настройки → Основные → Звук» выберите автоматический виртуальный микрофон или нажмите «Использовать для отправки» и сохраните изменения.

В приложении общения явно выберите CABLE Output. Системным микрофоном может оставаться физическое устройство. Нажмите «Проверить виртуальный микрофон» в настройках и проверьте звук тестом микрофона в приложении общения. Тон может быть слышен участникам текущего звонка. Кнопка подтверждает только попытку воспроизвести тестовый сигнал, а не факт его получения другой программой.

Для первой отправки выберите оригинальный текст, чтобы исключить ненастроенный сервис перевода. Затем введите текст или запишите речь в VoxBridge и отправьте её. Драйвер сам по себе не пересылает физический микрофон.

Если приложение общения работало до установки драйвера, после перезагрузки компьютера откройте его заново и повторно выберите устройство. Обнаружение и приём звука в QQ / WeChat нужно проверять отдельно.

Менеджер драйвера также доступен в меню «Пуск → VoxBridge → VB-CABLE - Install or Uninstall». При тихой установке, обновлении или уже установленном драйвере его установщик автоматически не запускается. Отмена установки драйвера не мешает установке приложения.

## Обновление приложения

Запустите новый установщик поверх старого. Предварительное удаление не требуется. Сохраняются исходная папка установки, конфигурация, параметры субтитров, сервисы и ключи; VB-CABLE заново не устанавливается.

Также можно открыть «Настройки → Основные → О программе → Проверить обновления» и выбрать «Обновить и перезапустить». Установка ждёт завершения прослушивания, записи, перевода текста, задач очереди и сохранения настроек. Уведомление объясняет, что нужно завершить.

Бездействующее отслеживание буфера и черновики не блокируют ручное обновление. Перед установкой отслеживание останавливается, текущие поля ввода и результаты перевода временно сохраняются локально. При следующем запуске они восстанавливаются, а копия удаляется. После загрузки повторно проверяются состояние задач и подпись пакета.

«Автоматические обновления» по умолчанию выключены; переключатель сохраняется сразу и отдельно. При включении приложение после запуска проверяет и загружает обновление, показывая ход загрузки. После проверки подписи, при отсутствии активных задач и несохранённой работы, начинается отсчёт пяти секунд до установки и перезапуска. Новая задача снова откладывает установку. «Позже» пропускает автоматическую установку до следующего запуска; выключение настройки отменяет ожидающий отсчёт. При ошибке загрузки или подписи текущая версия остаётся доступной, можно повторить вручную. Анимации состояния учитывают системное уменьшение движения.

Сохранение данных при обновлении относится к тому же компьютеру и пользователю Windows. При смене компьютера, пользователя или явном удалении данных требуется повторная настройка.

## Удаление приложения и драйвера

Программа удаления использует оформление установщика, поддерживает смену языка, сворачивание и разворачивание. Флажки «Удалить личные настройки и ключи» и «Открыть менеджер удаления драйвера» по умолчанию сняты. Отмена не удаляет приложение.

Перед удалением выйдите из VoxBridge через контекстное меню значка в трее. Скрытие в трей или сворачивание не завершает программу.

- **Удалить только приложение:** используйте «Установленные приложения» Windows или «Пуск → VoxBridge → Uninstall VoxBridge». По умолчанию настройки и драйвер сохраняются.
- **Удалить также личные настройки:** явно отметьте удаление данных. Это удалит конфигурации и ключи.
- **Удалить виртуальный микрофон:** откройте официальный менеджер, нажмите **Remove Driver** и перезагрузитесь по инструкции. Сначала убедитесь, что драйвер не нужен другим программам.

Интерактивное удаление предлагает открыть менеджер драйвера, по умолчанию сохраняя его. Если удаляете оба компонента, завершите удаление драйвера до удаления файлов VoxBridge. Если приложение уже удалено, скачайте [официальный пакет VB-CABLE](https://vb-audio.com/Cable/) для удаления оставшегося драйвера.

## Источник и лицензия драйвера

VB-CABLE предоставляется [VB-Audio](https://vb-audio.com/Cable/) и распространяется за добровольные пожертвования. Условия включения в другой продукт приведены в [Distribution with other product](https://vb-audio.com/Services/licensing.htm). В папке установки `virtual-microphone` сохранены оригинальные readme и лицензии. В комплект входит только базовая версия, без A+B / C+D. Корпоративные случаи, в которых пользователи не могут самостоятельно оплачивать лицензии, регулируются инструкциями поставщика.

Технические подробности установщика и обновлений — в [руководстве разработки на китайском](../development.md). Если устройство не появилось или нет звука, начните с [устранения неполадок](guides/troubleshooting.md).
