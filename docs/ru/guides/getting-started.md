# Начало работы

[Документация](../README.md) · Далее: [настройка сервисов](services.md)

## 1. Установка программы

Скачайте подходящий установщик из [Releases](https://github.com/Zhiruosama/VoxBridge/releases). Для обычной установки нужен DMG или EXE. Файлы подписей, контрольных сумм и Source code не являются установщиками.

| Платформа | Установщик | Поддержка |
| --- | --- | --- |
| Mac | Имя содержит `aarch64.dmg` | Apple Silicon, macOS 14.2 или новее |
| Windows | Имя содержит `x64-setup.exe` | Windows 11, компьютеры Intel / AMD |
| Windows ARM64 | Имя содержит `arm64-setup.exe` | Экспериментальная; работа с реальным аудиооборудованием ещё требует проверки |

Возможности русского интерфейса и OpenAI ASR зависят от версии установщика. До выпуска сборки с этими изменениями они доступны в исходном коде этой ветки; [инструкция сборки на китайском](../../development.md).

### Mac

Откройте DMG, перетащите VoxBridge в «Программы» и запустите оттуда. При обновлении замените старое приложение.

Приложение пока не подписано Developer ID и не нотарифицировано. Если первый запуск блокируется, убедитесь, что файл получен из репозитория проекта, затем разрешите запуск в разделе «Конфиденциальность и безопасность» по [инструкции Apple](https://support.apple.com/ru-ru/102445). Отключать защиту системы целиком не нужно.

### Windows

Запустите установщик и выберите папку, ярлыки и необходимость виртуального микрофона. Для перевода текста и просмотра субтитров виртуальный микрофон можно пока не устанавливать. Если отсутствует WebView2, установщик предложит установить среду выполнения.

Приложение Windows пока не подписано Authenticode. Для установки драйвера нужны права администратора. Подробности — в [руководстве для Windows](../windows-installation.md).

### Русский интерфейс

Откройте **Settings → General → Appearance → Interface language** либо **设置 → 常规 → 外观 → 界面语言**, выберите **Русский**, затем сохраните изменения. Язык главного окна и плавающих окон синхронизируется. Языки распознавания и перевода задаются отдельно.

## 2. Настройте только нужные сервисы

| Функция | Что настроить |
| --- | --- |
| Перевод введённого текста | Перевод текста |
| Перевод звука приложения в субтитры | Распознавание речи + перевод текста |
| Перевод введённого текста в речь | Перевод текста + синтез речи |
| Распознавание записи, перевод и озвучивание | Распознавание речи + перевод текста + синтез речи |

В настройках откройте нужный сервис, выберите пресет либо заполните адрес и модель вручную. Сохраните ключ API, затем изменения конфигурации. Пресеты не содержат ключей и оплаченной квоты. Подробнее — [настройка сервисов](services.md).

Для перевода текста не нужно разрешение на запись и не требуется настройка всех сервисов.

## 3. Попробуйте функцию

- **Перевод текста:** выберите слева «Перевод текста», задайте целевой язык, введите текст и нажмите Enter. Shift + Enter добавляет строку.
- **Субтитры:** выберите слева «Субтитры», укажите приложение, включите в нём звук и начните прослушивание.
- **Синтез речи:** внизу страницы субтитров выберите язык и голос, введите текст или запишите речь и отправьте. Сначала проверьте устройство отправки.

Чтобы приложение для общения получало синтезированную речь, настройте [голосовой ввод и виртуальный микрофон](voice-output.md). Прослушивание у себя управляется отдельной кнопкой с наушниками.

## 4. Обновление

При запуске приложение проверяет обновления. При наличии новой версии сверху появляется однократное уведомление: можно выбрать «Обновить» или «Позже». В этом запуске уведомление повторяться не будет. Если обновлений нет или проверка не удалась, уведомление не показывается. Проверить вручную можно в «Настройки → Основные → О программе».

Перед установкой сохраните черновики и настройки, завершите аудиозадачи. Также можно скачать новый установщик из Releases и установить поверх старого без предварительного удаления. На том же компьютере под тем же пользователем настройки и ключи сохраняются.

Правила сохранения и удаления драйвера Windows описаны в [платформенном руководстве](../windows-installation.md#удаление-приложения-и-драйвера). Подпись обновлений проверяет загруженный пакет и не заменяет подпись издателя Windows или Apple.

При проблемах сначала прочитайте [устранение неполадок](troubleshooting.md). Обычно не нужно переустанавливать приложение или повторно вводить все ключи.
