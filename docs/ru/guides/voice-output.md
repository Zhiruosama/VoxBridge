# Голосовой ввод и виртуальный микрофон

[Документация](../README.md) · [Настройка сервисов](services.md) · [Устранение неполадок](troubleshooting.md)

Передача речи проходит так: текст или запись → необязательный перевод → синтез речи → выбранное устройство вывода. Запись микрофона распознаётся и озвучивается заново; исходная запись напрямую не передаётся.

## Сначала проверьте, куда отправляется звук

**Устройство отправки определяет, что слышит собеседник; устройство прослушивания — что слышите вы.** Для передачи речи в приложение общения нужен виртуальный микрофон. Чтобы просто услышать звук у себя, используйте прослушивание.

| Платформа | Устройство отправки VoxBridge | Микрофон в приложении общения |
| --- | --- | --- |
| Mac | VoxBridge | VoxBridge |
| Windows | CABLE Input (VB-Audio Virtual Cable) | CABLE Output (VB-Audio Virtual Cable) |

Для прослушивания выберите системное устройство по умолчанию или свои наушники. Не назначайте виртуальный кабель обычным системным динамиком: иначе в разговор может попадать звук других приложений.

У новых пользователей отправка по умолчанию использует «Выбирать виртуальный микрофон автоматически (рекомендуется)». Если оба конца драйвера не готовы, приложение предложит установку или перезагрузку. Звук, предназначенный для звонка, не будет перенаправлен на динамики. Ранее сохранённые устройства не меняются автоматически. Чтобы сменить их, откройте «Настройки → Основные → Звук», выберите устройство отправки и сохраните изменения.

В приложении общения всё равно нужно явно выбрать вход из таблицы. VoxBridge не меняет системный микрофон Windows по умолчанию.

### Установка виртуального микрофона

Перед установкой драйвера завершите звонок.

- **Mac:** «Настройки → Основные → Звук → Виртуальный микрофон», затем установите драйвер VoxBridge по подсказкам.
- **Windows:** установите базовый VB-CABLE через установщик приложения или настройки и перезагрузите компьютер по инструкции поставщика. См. [руководство Windows](../windows-installation.md).

Система запросит права администратора. В Windows используется драйвер VB-Audio с сохранением сведений о поставщике. Переименование устройства не превращает его в собственный драйвер VoxBridge.

## Отправка введённого текста

Внизу страницы субтитров выберите язык вывода и голос, введите текст и отправьте. Enter по умолчанию запускает озвучивание; действие меняется в «Основные → Текстовый ввод → Действие по Enter». Shift + Enter добавляет строку.

- «Перевести» выполняет только перевод; оба языка появляются в области субтитров выше.
- «Оригинал / Перевод» определяет, какой текст озвучивается. Для оригинала предварительный перевод не нужен.
- Кнопка наушников управляет только тем, слышите ли вы отправляемую речь у себя.
- После отправки поле очищается, и можно вводить следующее сообщение.

Для первой проверки выберите оригинал и настройте синтез речи: это исключит влияние ещё не настроенного перевода. Для озвучивания перевода обычно нужна полноценная конфигурация перевода текста. Проверки нужных сервисов и устройства выполняются при использовании функции. При ошибке приложение предлагает перейти к настройке, сохраняет ввод и не ставит задачу в очередь. Постоянных уведомлений о конфигурации и маршруте в рабочем окне нет. Локальная проверка не подтверждает корректность ключа, баланс или работоспособность облачного сервиса.

Если нужен только текстовый результат, используйте [отдельный перевод текста](text-translation.md).

## Отправка записи

Нажмите микрофон, чтобы начать запись, затем нажмите ещё раз для завершения. Максимальная длительность — одна минута; запись можно отменить.

По умолчанию распознанный текст попадает в поле ввода: проверьте или исправьте его перед отправкой. Если включить «Отправлять сразу», завершение записи автоматически запускает распознавание, перевод и синтез. Если во время записи черновик изменился, приложение сначала ждёт подтверждения, чтобы избежать случайной отправки.

Физический микрофон выбирается в «Настройки → Основные → Звук → Микрофон голосового ввода». По умолчанию используется системный вход. Кнопки микрофона и клавиатуры в плавающем окне используют те же задачи и очередь, что и главное окно.

## Очередь, остановка и прослушивание

Откройте «Очередь», чтобы увидеть этапы, количество задач и целевой язык. В очереди может быть до 10 сообщений. Перевод и подготовка речи могут выполняться параллельно; воспроизведение идёт последовательно.

- Можно приостановить, продолжить, изменить, повторить или отменить отдельную задачу.
- Остановка текущего вывода приостанавливает последующие задачи. Для возобновления нажмите «Продолжить».
- Неудачные задачи сохраняют текст и не блокируют последующие. Повторная или изменённая задача помещается в конец очереди и может оплачиваться заново.
- Уже поставленные задачи сохраняют конфигурацию на момент отправки. Новые язык или голос влияют только на следующие задачи.
- Очередь существует только в текущем запуске. При выходе задачи отменяются.

Для отправки и прослушивания используется один результат синтеза. Переключение прослушивания во время воспроизведения не запускает синтез заново; если включить его посередине, будет слышна оставшаяся часть. Системное устройство для прослушивания определяется в момент начала воспроизведения, что удобно при частом подключении наушников.

## Проверка в Discord

1. В настройках голоса Discord выберите вход из таблицы выше. Для вывода оставьте наушники или динамики. В браузерной версии также разрешите доступ к микрофону.
2. Откройте тест микрофона Discord и отключите прослушивание в VoxBridge, чтобы не слышать два воспроизведения одновременно.
3. Отправьте короткую фразу из VoxBridge и убедитесь, что Discord её получает.
4. Если звук прерывается, попробуйте профиль входа «Студия», чтобы исключить влияние шумоподавления и эхоподавления. После проверки выключите тест микрофона.

На Mac основная проверка проводилась с Discord. На Windows проверена локальная передача через виртуальный кабель, но это не гарантирует совместимость со всеми клиентами звонков. Ограничения QQ, WeChat и других программ описаны в [устранении неполадок](troubleshooting.md#приложение-общения-не-видит-виртуальный-микрофон).
