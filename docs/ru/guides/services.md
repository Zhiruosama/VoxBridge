# Настройка сервисов

[Документация](../README.md) · [Начало работы](getting-started.md) · [Устранение неполадок](troubleshooting.md)

## Какой сервис нужен

Три типа сервисов настраиваются независимо. Они могут принадлежать разным поставщикам; можно сохранить несколько конфигураций и переключаться между ними.

| Раздел настроек | Назначение | Поддерживаемые API |
| --- | --- | --- |
| Перевод текста | Перевод введённого текста и распознанных субтитров | Chat Completions, совместимый с OpenAI, включая пресет DeepSeek |
| Распознавание речи | Звук приложений и записи микрофона | Qwen WebSocket, Qwen HTTP для короткого аудио, OpenAI Audio Transcriptions |
| Синтез речи | Преобразование текста в голос | MiniMax WebSocket, Speech API, совместимый с OpenAI |

Пресет помогает заполнить поля, но не гарантирует совместимость всех поставщиков, моделей и языков. Один и тот же ключ API не означает одинаковый протокол. Для расширения поддержки см. [границы совместимости API на китайском](../../08-provider-configuration.md).

## Сохранение конфигурации

1. Откройте нужный раздел настроек. В «Добавить конфигурацию» выберите пресет поставщика или создайте пустую конфигурацию.
2. Проверьте адрес API, модель и тип API. Для синтеза речи также нужен голос.
3. Введите свой ключ API и нажмите «Сохранить ключ».
4. Нажмите «Сохранить изменения» вверху страницы.

Конфигурация и ключ сохраняются отдельно. После изменения ключа сначала сохраните его, затем проверяйте сервис. После перезапуска ключ не нужно вводить снова. Пустая конфигурация не переключается автоматически на другой настроенный сервис.

## Распознавание речи OpenAI

Выберите **Распознавание речи → Добавить конфигурацию → Распознавание речи OpenAI**.

| Поле | Значение |
| --- | --- |
| Адрес API | `https://api.openai.com/v1` |
| Тип API | «Распознавание речи, совместимое с OpenAI» |
| Модель | `whisper-1`, `gpt-4o-transcribe`, `gpt-4o-mini-transcribe` или `gpt-4o-transcribe-diarize` |
| Ключ API | Ваш ключ с доступом к выбранной модели |

Полное имя модели с диаризацией — **`gpt-4o-transcribe-diarize`**, с `e` в конце. Приложение само добавляет `/audio/transcriptions` к базовому адресу. Не включайте этот путь в поле адреса.

Аудио отправляется как WAV в multipart-запросе. Запрашивается JSON с полем `text`; для модели с диаризацией также передаётся `chunking_strategy=auto`. VoxBridge использует текст расшифровки: отдельные метки говорящих и временные сегменты не отображаются и не сохраняются. Это HTTP-обработка коротких фрагментов, а не Realtime API OpenAI.

Конфигурация работает для записи микрофона, субтитров приложения и проверки короткого файла. В диагностике поддерживается WAV PCM16, моно, 16 кГц, длительностью 0,1–30 секунд и размером до 1 МБ. Во время записи или прослушивания приложение само готовит фрагменты нужного формата.

Можно задать другой совместимый адрес и ввести ID модели вручную. Совместимость зависит от реализации `/audio/transcriptions` у поставщика. Наличие модели в списке не подтверждает доступ к ней у вашего аккаунта. Формат API описан в [официальной документации OpenAI](https://developers.openai.com/api/reference/resources/audio/subresources/transcriptions/methods/create).

## Проверка сервиса

- **Перевод текста → Проверить подключение:** отправляет короткий текст и проверяет, может ли текущая модель перевести его с сохранённым ключом.
- **Синтез речи → Проверить подключение:** создаёт короткое тестовое аудио и удаляет его без воспроизведения и отправки в виртуальный микрофон.
- **Распознавание речи → Проверить конфигурацию:** проверяет готовность конфигурации и ключа. Для фактической проверки распознавания загрузите короткое аудио в разделе «Звук и диагностика». Для Qwen WebSocket используйте прослушивание приложения на странице субтитров.

Проверки перевода и синтеза вызывают сервис поставщика и могут оплачиваться. Личные клонированные голоса также оплачиваются по правилам поставщика. Проверку можно отменить. При изменении конфигурации предыдущий результат проверки теряет актуальность.

## Модели, голоса и свои пресеты

В выборе модели или голоса нажмите «Ввести вручную…», укажите поддерживаемый ID и подтвердите Enter. Esc отменяет ввод. Вручную подтверждённый голос добавляется в пресеты текущей конфигурации; после сохранения изменений он остаётся доступен при следующем запуске.

«Свои пресеты» позволяют дать удобные названия часто используемым моделям и голосам. Можно сохранить до 50 пресетов каждого типа; они разделены по конфигурации сервиса и протоколу. Удаление одного пресета не удаляет сервис или ключ. Удаление всей конфигурации удаляет и её ключ.

Личные клонированные голоса обычно привязаны к аккаунту поставщика. При смене аккаунта проверьте права на голос: копирования одного ID недостаточно.

## Стиль и языки перевода

«Перевод текста → Стиль перевода» управляет формулировками. По умолчанию используется естественный краткий стиль повседневного общения. Это поле не заменяет настройку целевого языка. Пустое поле означает инструкции по умолчанию.

Язык распознавания прослушиваемого аудио по умолчанию определяется автоматически. Язык субтитров меняется в «Основные → Субтитры прослушивания». Язык у поля ввода определяет целевой язык озвучивания; у отдельной страницы перевода текста свои настройки языка.

Среди языков речи и перевода доступны китайский, английский, японский, корейский, испанский, индонезийский, кантонский, финский, русский и немецкий. Качество и поддержка зависят от модели. Если совпадение языков подтверждено, текст может сразу озвучиваться; смешанный язык, неуверенное определение или письменный кантонский могут по-прежнему проходить через перевод.

## Скорость, эмоции и эффекты

В меню голоса внизу поля ввода можно переключать сервис синтеза, модель, голос и скорость. Это доступно и во время прослушивания. Новые задачи используют новые настройки, а уже поставленные в очередь и воспроизводимые — настройки на момент отправки.

Для MiniMax доступны эмоции, громкость, высота тона и дополнительные эффекты. Другим API эти параметры не отправляются. Список эмоций зависит от модели; неподдерживаемые параметры не навязываются.

- Громкость по умолчанию — 1, высота тона — 0. Если не уверены, оставьте эти значения.
- Дополнительные настройки включают изменение тембра, эффекты и замены произношения. Результат лучше проверить на своём голосе.
- Для замены произношения указывайте по одной паре `слово/произношение` на строку, например `VoxBridge/vox bridge`; до 50 строк.
- Некоторые модели понимают метки пауз и эмоций. Перевод может изменить или удалить их; не считайте их универсальным синтаксисом.

Режим рассуждений в параметрах сервиса задавайте только при явной поддержке поставщиком. В остальных случаях оставьте «По умолчанию у сервиса», чтобы дополнительные параметры не вызвали ошибку.

## Данные и оплата

Текст и аудио отправляются настроенному поставщику модели и оплачиваются по его правилам. VoxBridge не предоставляет облачную квоту и не включает личные голоса в установщик.

Ключи хранятся в локальном закрытом хранилище и не попадают в обычный файл настроек, историю перевода или текст диагностических журналов. Не отправляйте ключи, записи и полные личные конфигурации в сообщениях об ошибках. См. [журналы диагностики](../diagnostics.md).
